# 판(스테이지) 파일

`village/index.html?stage=<id>` 로 열면 `village/stages/<id>.json` 을 읽어 그 판을 얹는다.
`?stage` 가 없으면 **기본 판 = 지금 마을 그대로**다(달라지는 것 0 — 시뮬 도구로 시드별 확인).
엔진 제안서 ② · `docs/village_engine_proposal.md` · 사회시뮬 흡수 C1·C2·C4·C10 · `docs/village_socialsim_absorb.md`

## 운영 안전
- 판이 있으면 저장 키가 따로다: `rpg.village.<sid>.<id>`. 아이의 기본 마을 저장본은 건드리지 않는다.
- 판에서는 **원격 동기(sync.js)를 끈다.** 운영 DB 에 닿지 않고, 이 기기에만 저장한다.
- 친구 마을 구경(`?visit=`)에서는 판을 무시한다.

## 칸
| 칸 | 뜻 | 예 |
|---|---|---|
| `id` | 파일 이름과 같다. 소문자·숫자·`-` | `"jobs-short"` |
| `이름` | 판 이름(교사용) | `"일자리가 모자란 동네"` |
| `교과` | `docs/village_curriculum_map.md` 표의 단원 칸 그대로(검사가 확인) · 없으면 null | `"4-1 · 경제활동과 지역 간 교류"` |
| `질문` | 판을 열 때 한 줄(C1) · 아이 말로, 교과 용어 없이 | `"어른들이 일하러 갈 곳이 먼 집은 어디일까요?"` |
| `되돌아보기` | 판 목표를 다 이루면 한 줄(C1) | `"일터를 어디에 지었더니 풀렸나요?"` |
| `현상` | 이 판이 보여 줄 것 한 줄(교사용 · 시뮬 발생률의 바탕) | |
| `변수` | 앞 판과 다르게 켜는 것 하나(C2) — 규칙 칸의 키 | `"jobsHomes"` |
| `시작` | 시작 땅 저장본(`village/` 기준 경로) · null 이면 빈 땅. 그 판의 저장본이 이미 있으면 쓰지 않는다 | `"stages/boards/pop167.json"` |
| `규칙` | `VRULES` 덮기. 끄기도 여기서 한다(C4) | `{ "jobsHomes": { "on": true } }` |
| `건물` | 쓸 건물 목록 · null 이면 전부. 목록 밖은 트레이에서 빠지고 놓기도 막는다(길 `road` 필수) | `["road","house","well","shop"]` |
| `목표` | 목표판 맨 앞에 오른다. 셈 꼴 세 가지(아래) | |
| `모습` | **컨셉 스킨**(엔진 5번) — 계절 고정과 바닥·풀색을 **한 칸에 묶는다**(따로 두면 계절이 돌 때 색이 도로 섞인다) | `{ "계절":"가을", "풀":"#c9bd6a", "바닥":"#b59a4f" }` |
| `건물정의` | **그 판에서만 쓰는 새 건물**을 K 에 더한다(아래) · 있는 종류는 덮지 않는다 | `{ "field": { "nm":"밭", … } }` |
| `흐름` | **물건이 나고 옮겨지고 쓰이는 것**(아래) — 생활 판정은 한 줄도 안 바꾼다 | `{ "on": true, "물건": "곡식", … }` |

**목표 셈**
- `{ "t": "가게 3채", "셈": "kind", "k": "shop", "n": 3 }` — 그 종류 n개 이상
- `{ "t": "주민 60명", "셈": "pop", "n": 60 }` — 인구 n 이상
- `{ "t": "일할 곳이 닿는 집 95%", "셈": "hook", "훅": "일닿음%", "n": 95, "비교": ">=" }` — `STAGE_HOOKS`(index.html `[MAC-STAGE]`) 값과 비교. 지금 훅: `일닿음%`

## `모습` · `건물정의` — 컨셉 스킨 (`[MAC-SKIN]` · 조사 `docs/village_skin_scan.md`)

**코드를 한 줄도 안 고치고 판 파일만으로 다른 컨셉의 마을을 연다.** 보기: `farm.json`(`?stage=farm`).

```json
"모습": { "계절": "가을", "풀": "#c9bd6a", "바닥": "#b59a4f" },
"건물정의": {
  "barn": { "nm": "헛간", "ic": "🏚️", "grp": "건물", "w": 2, "h": 2, "jobs": 3, "needRoad": true, "cap": 40,
    "parts": [ { "g": "box",  "c": "red",     "s": [1.7, 2.2, 1.7], "p": [0, 1.1, 0] },
               { "g": "half", "c": "#8c4038", "s": [1.85, 1.1, 1.85], "p": [0, 2.2, 0] } ] }
}
```

- **`모습`**: `계절`은 `봄·여름·가을·겨울` 중 하나(그 판에서는 계절이 돌지 않고 '🌸 봄이 왔어요' 알림도 안 뜬다) · `풀`·`바닥`은 `#rrggbb` 또는 팔레트 이름(`"grass"`).
- **`건물정의`**: 종류 이름은 소문자·숫자·`_`(2~16자). **이미 있는 종류는 덮지 않는다**(그림이 달라지면 저장본이 어긋난다).
  - `parts` 한 조각: `g` = `box`·`cyl`·`cone`·`half`·`sph` · `c` = `#rrggbb` 또는 팔레트 이름 · `s`(크기)·`p`(자리)의 **x·z 는 칸 단위**(코드가 칸 크기를 곱한다) · y 는 그대로.
  - `grp`(트레이 탭)는 쉬운 말로: `길`·`바닥` → 길 탭 · `집`·`건물`·`가게` → 집·가게 · `쉼`·`놀이` · `자연`·`키 큰 것` · `꾸밈`·`낮은 것`·`긴 것` · `시설`·`특별`. 안 쓰면 `jobs`/`need` 가 있으면 집·가게, 없으면 꾸밈.
  - `need`(필요를 채움) · `jobs`(일자리 수) · `needRoad`(길에 붙어야 놓임) · `w`·`h`(1~4) · `cap`(최대 개수)도 판 파일에서 준다.
  - 새 종류는 **해금 표에 없으니 처음부터 열려 있다.**
- **차례**: 건물정의 → 모습 → 건물 목록 거르기(거르기는 `K` 에 있는 것만 남기므로 새 종류가 먼저 들어가야 한다).
- **판 밖으로 나가면**: 판 전용 종류가 든 저장본을 파일로 기본 마을에 가져오면 **"이 마을에 없는 것이 있어요(…)"** 한마디가 뜨고 그 칸은 비어서 열린다(조용히 버리지 않는다).
- 판 검사(`stages.mjs`)가 두 칸을 본다: 모양 조각 꼴 · 이미 있는 종류를 덮으려 하는지 · **판을 실제로 열었을 때 그 종류가 생겼는지**.
- 이번에 넣지 않은 것(조사 문서의 ③④⑤⑦): 하늘·빛 · 바깥 숲 종류 · 칭호 · 해금 표.

## `흐름` — 밭에서 난 것이 가게로 가고 세대가 쓴다 (`[MAC-FLOW]` · 설계 `docs/village_flow_design.md`)

```json
"흐름": { "on": true, "물건": "곡식",
  "만드는곳": { "field": { "간격틱": 600, "양": 1, "담을수": 5 } },
  "받는곳":  { "shop":  { "담을수": 8 } },
  "쓰는시각": 12, "세대몫": 1, "운반상한": 4, "칸당틱": 6 }
```

- 이 칸이 없으면 **아무 일도 일어나지 않는다**(기본 마을은 그대로).
- **생활 판정과 섞이지 않는다** — 필요·성장·이사·돌아섬·붐빔·일자리를 한 줄도 안 바꾼다. 재고가 비어도 **주민이 떠나거나 집이 퇴화하지 않는다.** 그래서 `rules.json` 분류는 **'물건'**(판 검사에서 세지 않는다).
- **상태 이름**(디자인·연기와 함께 쓰는 계약): 밭 `growing`·`ready`·`full` · 운반 `waiting`·`moving`·`cut` · 가게 `stocked`·`empty` · 세대 `got`·`missed`.
- **생산**: 만드는곳마다 `간격틱`에 `양`만큼 제 안에 쌓는다. `담을수`까지 — 꽉 차면 **만들지 않는다**(`full`).
- **운반**: 밭의 문 앞 길에서 가게의 문 앞 길로 길이 이어지면 **가까운 가게부터**. 동시에 `운반상한`까지, 걸리는 틱 = 길 거리 × `칸당틱`(**멀면 늦게 온다**).
- **소비**: 식구가 있는 집마다 하루 한 번 `세대몫`을 닿는 가게 중 가까운 곳에서 뺀다. **걷는 주민 수와 무관하다.**
- **길이 끊기거나 가게가 없어지면** 운반 중인 것은 **출발한 밭으로 돌아간다**(안 잃어버린다). 다시 이으면 저절로 간다.
- **저장**: 저장본의 `flow` 칸에 밭·가게 양 · 운반 중인 것 · 세대의 '오늘 받았나'가 담긴다. 옛 저장본에 그 칸이 없으면 0에서 시작하고, 옛 코드는 모르는 칸이라 무시한다.
- **연기·디자인이 읽는 계약**: `window.FLOW(root)` → `growing`·`ready`·`full`·`waiting`·`moving`·`cut`(밭) · `stocked`·`empty`(가게) · `got`·`missed`(집) · 그 밖은 `null`. **밖으로 나가는 것은 이 함수 하나뿐**이다.
- 확인용 훅: `window.__flow()` · `window.__flowAt(x, y)`(빈 가게면 **까닭**도 함께).

## 판 카드 (C11 · `[MAC-STAGECARD]`)
- **수업 판**(`교과` 칸이 있는 판)을 처음 열면 시작 카드가 뜬다: 판 이름·교과(작게) · 🔎 `질문` · 🎯 목표 · **첫날 한 장**(그때 찍어 둔다) · [시작].
- 판 목표를 다 이루면 같은 틀의 끝 카드가 뜬다: **첫날 ↔ 오늘** 두 장(같은 틀로 찍음) · 새로 생긴 것을 그림으로(🏪🏪🏪 · 길은 🛣️ 세 개 + 칸 수) · 💭 `되돌아보기` · [닫기]. 한 번 닫으면 목표로는 다시 안 뜬다.
- **교사가 닫기**: 주소 끝에 `#끝`을 붙여 열면 언제든 끝 카드가 뜬다.
- 사진·첫날 물건 수는 `localStorage 'rpg.stagecard.<sid>.<id>'`에 둔다(저장본·sync 0). 자유 놀이 판(town)과 기본 판에는 카드가 없다.

## `rules.json` — 규칙마다 무엇을 바꾸나 (C10)
`판정`(인구·필요·층·이사·돌아섬·일자리·붐빔 셈을 바꾼다) · `바로잡음`(원래 있던 장치를 화면 말과 맞추는 고침 — 새 장치가 아니라 세지 않는다 · growPause) · `때`(하루 합은 그대로, 시각만 옮긴다 — dayMoveIn) · `목표` · `조작` · `말` · `보기` · `연기` · `성능` · `저장·안전`.
**새 VRULES 를 넣으면 여기에 한 줄 더한다.** 빠지면 검사가 FAIL 이다.

## 검사
```bash
node scripts/village-sim/stages.mjs                          # 칸·교과·시작 땅·규칙·건물·분류·판정 규칙 수 · 시뮬로 얹어 하루
node scripts/village-sim/run.mjs --stage jobs-short --days 2 --seeds 1-5 --vs '가게6: do=put shop @jobs 6'
```
- 판이 기본에서 바꾸는 판정 규칙 ≤ 3 → 넘으면 FAIL(C2).
- **수업 판**(`교과` 칸이 있는 판)은 켜진 판정 규칙 ≤ 6 → 넘으면 FAIL. **자유 놀이 판**(`교과: null` — town)은 면제(보스 09-20). 지금 기본 판은 판정 6개다.
