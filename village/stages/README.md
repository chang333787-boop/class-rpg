# 판(스테이지) 파일

`village/index.html?stage=<id>` 로 열면 `village/stages/<id>.json` 을 읽어 그 판을 얹는다.
`?stage` 가 없으면 **기본 판 = 지금 마을 그대로**다(달라지는 것 0 — 시뮬 도구로 시드별 확인).
엔진 제안서 ② · `docs/village_engine_proposal.md` · 사회시뮬 흡수 C1·C2·C4·C10 · `docs/village_socialsim_absorb.md`

## 운영 안전
- 판이 있으면 저장 키가 따로다: `rpg.village.<sid>.<id>`. 아이의 기본 마을 저장본은 건드리지 않는다.
- 판에서는 **원격 동기(sync.js)를 끈다.** 운영 DB 에 닿지 않고, 이 기기에만 저장한다.
- 친구 마을 구경(`?visit=`)에서는 판을 무시한다.

## 칸
| 칸 | 뜻 | 예 |
|---|---|---|
| `id` | 파일 이름과 같다. 소문자·숫자·`-` | `"jobs-short"` |
| `이름` | 판 이름(교사용) | `"일자리가 모자란 동네"` |
| `교과` | `docs/village_curriculum_map.md` 표의 단원 칸 그대로(검사가 확인) · 없으면 null | `"4-1 · 경제활동과 지역 간 교류"` |
| `질문` | 판을 열 때 한 줄(C1) · 아이 말로, 교과 용어 없이 | `"어른들이 일하러 갈 곳이 먼 집은 어디일까요?"` |
| `되돌아보기` | 판 목표를 다 이루면 한 줄(C1) | `"일터를 어디에 지었더니 풀렸나요?"` |
| `현상` | 이 판이 보여 줄 것 한 줄(교사용 · 시뮬 발생률의 바탕) | |
| `변수` | 앞 판과 다르게 켜는 것 하나(C2) — 규칙 칸의 키 | `"jobsHomes"` |
| `시작` | 시작 땅 저장본(`village/` 기준 경로) · null 이면 빈 땅. 그 판의 저장본이 이미 있으면 쓰지 않는다 | `"stages/boards/pop167.json"` |
| `규칙` | `VRULES` 덮기. 끄기도 여기서 한다(C4) | `{ "jobsHomes": { "on": true } }` |
| `건물` | 쓸 건물 목록 · null 이면 전부. 목록 밖은 트레이에서 빠지고 놓기도 막는다(길 `road` 필수) · 되살리기도 막는다 — 예외: 개울 다리·판 개울·옛 우물(물을 끈 판에서 되살리기·옮기기·되돌리기 · [MAC-STAGEKEEP]) · `[]`은 전부 허용 — 아이 손은 `트레이`로(판 검사 FAIL) | `["road","house","clinic","shop"]` |
| `트레이` | **아이 손**(`[MAC-TRAY]`) — 아이 트레이 · 놓기 · 치우기 · 옮기기 · 길게 누름 메뉴가 이 종류만(건물 목록 안 · 엔진이 띄우는 종류) · `[]` = 트레이 비움 + 🖐️·🧽 숨김 · 없으면 `건물`이 다 정한다. 되살리기 · 되돌리기 · 결정 적용 · 개울 다리(트레이에 길이 있을 때)는 지난다 · **엔진의 셈(이을 칸 · 넓힐 자리)은 트레이를 모른다** — 막는 것은 아이 손뿐 · 손에서 개울 다리는 길, 아파트는 `apart` 카드로 본다 · 역할에 `잇기`가 있으면 트레이에 길 종류가 있어야 한다(판 검사) | `["road","bench"]` |
| `판규칙` | **그 판에서만 켜는 규칙**(`[MAC-CAMP]` · CAMP) — 흰 목록 키만 읽고(밖의 키는 엔진이 버림 · 판 검사 REVIEW) 덮기마다 `뜻` 한 줄(없으면 FAIL). 지금 엔진이 하는 칸 = `멈춤` 의 `이사`(새 이웃 0) · `층자람`(층 오름 0) · `생산`(만드는곳이 새로 안 만듦 — 모형 화면 ⏸ 와 같은 스위치 · 그 단추도 숨김 · 쌓인 것은 그대로 오가고 쓰임) · `일자리`(일하러 나서는 사람 0 · 배정 · 집 카드 일자리 말은 그대로 셈 · `[MAC-CLOCK]`) — `성장` 은 받되 하는 일 없음 · 아직 안 하는 칸은 판 검사 REVIEW. **화면 말은 아직 없다** — `멈춤.이사` 인데 빈집이 생길 수 있는 판(아이 손에 집 · 아파트 · 열자마자 빈집)은 판 검사 REVIEW(빈집 말이 그대로 '곧 누가 걸어올 거예요'). 판 `규칙` 으로 `camp` 를 덮으면 FAIL(CAMP 를 안 쓰려면 이 칸을 뺀다) · 콘솔 되돌리기 `VRULES.camp.on = false` · 탐침 `__campStats()` | `{ "멈춤": { "이사": true, "층자람": true, "뜻": "…" } }` |
| `목표` | 목표판 맨 앞에 오른다. 셈 꼴 세 가지(아래) | |
| `모습` | **컨셉 스킨**(엔진 5번) — 계절 고정과 바닥·풀색을 **한 칸에 묶는다**(따로 두면 계절이 돌 때 색이 도로 섞인다) | `{ "계절":"가을", "풀":"#c9bd6a", "바닥":"#b59a4f" }` |
| `건물정의` | **그 판에서만 쓰는 새 건물**을 K 에 더한다(아래) · 있는 종류는 덮지 않는다 | `{ "field": { "nm":"밭", … } }` |
| `등급` | **같은 모습 잣대**(`[LK-CARD]` · 아래) — `"캠페인"`(없으면 이것 · 수업 판 · 조작 · 보기 스위치를 끄지 않음) · `"유즈맵"`(양상을 바꿔도 되나 모습 · 누르는 느낌은 지킴) | `"캠페인"` |
| `양상` | 유즈맵 판만 — 무엇이 바뀌나 한 낱말: `회의` · `지도` · `표` | `"지도"` |
| `흐름` | **물건이 나고 옮겨지고 쓰이는 것**(아래) — 생활 판정은 한 줄도 안 바꾼다 | `{ "on": true, "물건": "곡식", … }` |
| `시작칸` | 판을 열 때 **화면 가운데로 올 칸**과 가장 먼 시작 배율(`[MAC-STARTCELL]` · 없으면 물건들의 가운데) — 카메라는 보기라 판정 0 | `{ "칸": [139.5, 138.5], "배율": 16 }` |
| `배속최대` | 그 판에서 가장 빠른 배속(`[MAC-CLOCK]`) — `1` · `2` · `4` 만(밖이면 판 검사 FAIL) · 더 빠른 배속 단추를 숨기고, 열 때(저장본 `clock.speed`) · 배속 단추 · Space 를 그 값까지 깎는다 · 없으면 4× 까지 · 4 보다 작은데 첫 안내가 뜰 수 있는 판(`첫안내` ≠ false · `시작` 없음)은 판 검사 REVIEW(셋째 장이 '2× 4×'를 권함) | `2` |
| `생산멈춤` | `false` = 모형 화면(동네 둘 판)의 '⏸ 생산 멈춤 · ▶ 생산 다시' 단추를 숨긴다('🔗 공급 경로 보기'는 둠) · 불(true · false)만(판 검사 FAIL) · 없으면 단추 뜸 | `false` |
| `안내최대층` | **안내 층**(`[MAC-K7]` · 1 현상 → 2 까닭 → 3 할 일 → 4 자리 ✨) — `2` = 탐정 판: 카드마다 제 현상 · 까닭만(가게 '빈 선반이에요' · 밭 '길이 끊겨 못 가요') · 할 일 꼬리(주민 풍선 뜻 '…지어 주세요' · 흐름 카드 '…이으면 가게에 닿아요' · 집 카드 📚 · 🛣️ 귀띔 · 💼 긴 말 · 🔗 공급 경로 말 꼬리) 0 · 💬 바람 주민 카드는 그 집 카드의 현상 말('💬 가게에 물건이 없어요 — …' · '…이 있으면 좋겠어요' 0 · 바람이 생기는 셈은 그대로) · 빈 가게 문 앞 팻말(까닭 그림) 0 · 짚기 ✨ 0(가게 · 밭 · 집 누름 · 💼 칩 — 🎯 목표판 줄 누름 · 🔗 공급 경로의 ✨ 는 둠) · `3` = 지금 그대로 · 2 · 3 만(판 검사 FAIL `안내 층 꼴`) · 2 인데 `권유`가 있으면 FAIL `탐정 판 권유` · 없으면 3 · 되돌리기 `VRULES.k7.on = false` | `2` |

- 트레이 판은 값 줄 숨김 — 카드 아래 값 줄('무료' · 'nG' · '내 집')을 숨긴다(잠긴 카드의 🔒 까닭 · 'NEW' 표지는 둔다 · 다시 보이기 `VRULES.stageTray.price = false` · 트레이를 끄기 `VRULES.stageTray.on = false`). 트레이에 안 뜨는 종류는 🔓 해금 소식에서 빠지고, 보기 모드 물건 말에서 할 수 없는 손 · 카드 말을 뺀다. 화면 확인: `node scripts/village-d/dcheck.mjs --scene tray`. 아는 칸(`stages.mjs` 의 `KNOWN`) 밖의 칸은 판 검사가 REVIEW 로 알린다(오타 잡기).
- 판 시계(`[MAC-CLOCK]` · 칸 없음 — 판이면 늘): 첫 프레임 전부터 시계를 쥐고(규칙 덮기 전 틱 0), 시작 카드가 뜨면 닫힐 때까지 그대로 · 처음 뜬 시작 카드의 [시작] = 판 시간 시작(저장본 speed 0 이어도 1배속) · 카드가 안 뜨는 판(교과 · `카드` 칸 없음 · `#끝` · 이미 시작함)은 규칙 뒤 곧바로 흐른다 · 카드가 끝내 안 뜨거나 판을 싣다 module 이 죽어도 8초 뒤 흐른다(첫 안내가 떠 있는 동안은 기다림 · 안전망은 쥐는 자리에서 건다) · 수업 판(교과 있음)의 ❓ 풍선 뜻 카드는 시계가 멈춘 동안만 열린다(도는 동안 누르면 짧은 말). 시계를 쥐는 이(제목 카드 · 첫 안내 · ❓ · 판 시계)는 한 곳(`clockHold`)에서 세어 서로 풀지 않는다 — 기본 마을도(첫 안내 · ❓ · 칭호 카드가 쥔 동안 배속 단추 · Space 는 다시 쥐고, 저장본 `clock.speed` 는 0 대신 풀린 뒤의 배속). 되돌리기 `VRULES.stageClock.on = false`(판 시계 · ❓ 여는 조건 · 다시 쥠 · 저장 배속 고침을 끔 — 쥐는 이 한 곳 셈만 남음) · 탐침 `__clockHold()` · 화면 확인 `node scripts/village-d/dcheck.mjs --scene start-card`.
- 💬 주민 소식 · 길 끌기(`[MAC-K7]` ⓪ · 칸 없음 — 판이면 늘): `?stage=` 판은 `VRULES.chirp` · `VRULES.roadLine` 기본 끔(💬 는 걱정하는 집 목록을 한눈에 줘 '알아내기'를 대신함 · 길 끌기는 0차시 조작 밖) · 판 `규칙`이 켜면 켠다(`{ "chirp": { "on": true } }`) · W·A·S·D 는 켬 그대로 · 자유 모드(판 없음)는 셋 다 그대로. 길 끌기 끔 = 곧은 줄 미리 보기만 끔(끌어 여러 칸 놓기는 그대로). 판 파일 받기가 늦어도(학교망) 💬 단추가 먼저 생기지 않고, 도중에 끄면 단추 · 창을 지운다. 화면 확인 `node scripts/village-d/dcheck.mjs --scene k7 --net-delay 2500:stages/`.

**목표 셈**
- `{ "t": "가게 3채", "셈": "kind", "k": "shop", "n": 3 }` — 그 종류 n개 이상
- `{ "t": "주민 60명", "셈": "pop", "n": 60 }` — 인구 n 이상
- `{ "t": "일할 곳이 닿는 집 95%", "셈": "hook", "훅": "일닿음%", "n": 95, "비교": ">=" }` — `STAGE_HOOKS`(index.html `[MAC-STAGE]`) 값과 비교. 지금 훅: `일닿음%`

## `모습` · `건물정의` — 컨셉 스킨 (`[MAC-SKIN]` · 조사 `docs/village_skin_scan.md`)

**코드를 한 줄도 안 고치고 판 파일만으로 다른 컨셉의 마을을 연다.** 보기: `farm.json`(`?stage=farm`).

```json
"모습": { "계절": "가을", "풀": "#c9bd6a", "바닥": "#b59a4f" },
"건물정의": {
  "barn": { "nm": "헛간", "ic": "🏚️", "grp": "건물", "w": 2, "h": 2, "jobs": 3, "needRoad": true, "cap": 40,
    "parts": [ { "g": "box",  "c": "red",     "s": [1.7, 2.2, 1.7], "p": [0, 1.1, 0] },
               { "g": "half", "c": "#8c4038", "s": [1.85, 1.1, 1.85], "p": [0, 2.2, 0] } ] }
}
```

- **`모습`**: `계절`은 `봄·여름·가을·겨울` 중 하나(그 판에서는 계절이 돌지 않고 '🌸 봄이 왔어요' 알림도 안 뜬다) · `풀`·`바닥`은 `#rrggbb` 또는 팔레트 이름(`"grass"`).
- **`건물정의`**: 종류 이름은 소문자·숫자·`_`(2~16자). **이미 있는 종류는 덮지 않는다**(그림이 달라지면 저장본이 어긋난다).
  - `parts` 한 조각: `g` = `box`·`cyl`·`cone`·`half`·`sph` · `c` = `#rrggbb` 또는 팔레트 이름 · `s`(크기)·`p`(자리)의 **x·z 는 칸 단위**(코드가 칸 크기를 곱한다) · y 는 그대로.
    ⚠ **`s`·`p` 의 단위가 가로세로와 높이가 다르다** — 가로·세로(`s[0]`·`s[2]`, `p[0]`·`p[2]`)는 **칸**(1 = 한 칸), 높이(`s[1]`·`p[1]`)는 **세계 단위**(한 칸 = 4).
    그래서 1×1 물건의 가로는 **1 을 넘으면 안 된다.** 기본 나무(`tree`)를 본떠 `s:[1.45, 1.35, 1.45]` 라고 적으면 가로만 4배가 되어 **납작한 판**이 된다
    (index.html 의 `K` 에 직접 적힌 값은 전부 세계 단위라 그대로 베끼면 안 된다). 전나무를 그렇게 적었다가 초록 상자가 나왔다 — 가로 0.5 안팎이 맞다.
  - `grp`(트레이 탭)는 쉬운 말로: `길`·`바닥` → 길 탭 · `집`·`건물`·`가게` → 집·가게 · `쉼`·`놀이` · `자연`·`키 큰 것` · `꾸밈`·`낮은 것`·`긴 것` · `시설`·`특별`. 안 쓰면 `jobs`/`need` 가 있으면 집·가게, 없으면 꾸밈.
  - `need`(필요를 채움) · `jobs`(일자리 수) · `needRoad`(길에 붙어야 놓임) · `w`·`h`(1~4) · `cap`(최대 개수)도 판 파일에서 준다.
  - 새 종류는 **해금 표에 없으니 처음부터 열려 있다.**
- **차례**: 건물정의 → 모습 → 건물 목록 거르기(거르기는 `K` 에 있는 것만 남기므로 새 종류가 먼저 들어가야 한다).
- **판 밖으로 나가면**: 판 전용 종류가 든 저장본을 파일로 기본 마을에 가져오면 **"이 마을에 없는 것이 있어요(…)"** 한마디가 뜨고 그 칸은 비어서 열린다(조용히 버리지 않는다).
- 판 검사(`stages.mjs`)가 두 칸을 본다: 모양 조각 꼴 · 이미 있는 종류를 덮으려 하는지 · **판을 실제로 열었을 때 그 종류가 생겼는지**.
- 이번에 넣지 않은 것(조사 문서의 ③④⑤⑦): 하늘·빛 · 바깥 숲 종류 · 칭호 · 해금 표.

## `흐름` — 밭에서 난 것이 가게로 가고 세대가 쓴다 (`[MAC-FLOW]` · 설계 `docs/village_flow_design.md`)

```json
"흐름": { "on": true, "물건": "곡식",
  "만드는곳": { "field": { "간격틱": 600, "양": 1, "담을수": 5 } },
  "받는곳":  { "shop":  { "담을수": 8 } },
  "쓰는시각": 12, "세대몫": 1, "운반상한": 4, "칸당틱": 6 }
```

- 이 칸이 없으면 **아무 일도 일어나지 않는다**(기본 마을은 그대로).
- **생활 판정과 섞이지 않는다** — 필요·성장·이사·돌아섬·붐빔·일자리를 한 줄도 안 바꾼다. 재고가 비어도 **주민이 떠나거나 집이 퇴화하지 않는다.** 그래서 `rules.json` 분류는 **'물건'**(판 검사에서 세지 않는다).
- **말**(`"말": { "growing": "고기 잡는 중", "ready": "잡은 생선이 있어요" }`) — 만드는곳의 두 말(`growing`·`ready`)만 판이 바꾼다. 없으면 밭의 말(자라는 중·거둘 것이 있어요) 그대로. 빈 가게의 까닭 말은 '밭' 대신 **만드는곳의 이름**(`nm`)을 쓴다 — 「부두가 아직 고기 잡는 중이에요 — 부두를 더 만들어 볼까요?」(`[MAC-FLOWWORDS]` · 보기: `sea.json`·`mountain.json`). 몫을 못 받은 집은 집 카드가 '🛒 가게에 물건이 없어요'(`[MAC-FLOWSAY]`)이고 그 집 주민의 🛒? 풍선 뜻도 같은 까닭('머리 위 🛒? 가게에 물건이 없어요' · 할 일 꼬리 없음 — 옛 '가게가 멀어요 — 집 가까이 지어 주세요'는 가게가 옆인데 멂으로 읽은 거짓 까닭 · PA-07 고침 · `VRULES.flowSay` 로 함께 켜고 끔).
- **모습·일꾼**(`[MAC-FLOWMAKER]`) — 곡식 이랑·이삭·자루는 **만드는곳이 `field`(밭)일 때만** 얹는다. 다른 만드는곳(부두·벌목장 …)은 **제 모양 그대로 + 쌓인 양만 상자로**(끊기면 흐리게). 빈 가게 팻말 그림도 밭 판은 밭, 다른 판은 상자(탐정 판 — `안내최대층` 2 — 은 팻말째 안 선다 · `[MAC-K7]`). 만드는곳에 `jobs` 가 있으면 일꾼이 문 밖에서 일하고, 나르는 사람은 상자를 진다. 흐름이 꺼진 판(기본 마을)은 한 사람도 안 달라진다.
- **수레**(`[MAC-FLOWCART]`) — 운반 중인 짐은 **수레 하나**가 **짐과 같은 시계로 실제 길 칸을 따라** 간다(떠 가는 🎒 아이콘 대신). 가게에 닿는 틱에 선반 수가 오르고 가게 모습도 그 틱에 다시 합친다. 나르는 사람(연기)은 표본이라 막혀도 수레는 안 막힌다. 끄기: `VRULES.flowLook.수레 = false`.
- **상태 이름**(디자인·연기와 함께 쓰는 계약): 밭 `growing`·`ready`·`full` · 운반 `waiting`·`moving`·`cut` · 가게 `stocked`·`empty` · 세대 `got`·`missed`.
- **생산**: 만드는곳마다 `간격틱`에 `양`만큼 제 안에 쌓는다. `담을수`까지 — 꽉 차면 **만들지 않는다**(`full`).
- **운반**: 밭의 문 앞 길에서 가게의 문 앞 길로 길이 이어지면 **가까운 가게부터**. 동시에 `운반상한`까지, 걸리는 틱 = 길 거리 × `칸당틱`(**멀면 늦게 온다**).
- **소비**: 식구가 있는 집마다 하루 한 번 `세대몫`을 닿는 가게 중 가까운 곳에서 뺀다. **걷는 주민 수와 무관하다.**
- **길이 끊기거나 가게가 없어지면** 운반 중인 것은 **출발한 밭으로 돌아간다**(안 잃어버린다). 다시 이으면 저절로 간다.
- **저장**: 저장본의 `flow` 칸에 밭·가게 양 · 운반 중인 것 · 세대의 '오늘 받았나'가 담긴다. 옛 저장본에 그 칸이 없으면 0에서 시작하고, 옛 코드는 모르는 칸이라 무시한다.
- **연기·디자인이 읽는 계약**: `window.FLOW(root)` → `growing`·`ready`·`full`·`waiting`·`moving`·`cut`(밭) · `stocked`·`empty`(가게) · `got`·`missed`(집) · 그 밖은 `null`. **밖으로 나가는 것은 이 함수 하나뿐**이다.
- 확인용 훅: `window.__flow()` · `window.__flowAt(x, y)`(빈 가게면 **까닭**도 함께).

## 판 카드 (C11 · `[MAC-STAGECARD]`)
- **수업 판**(`교과` 칸이 있는 판)을 처음 열면 시작 카드가 뜬다: 판 이름·교과(작게) · 🔎 `질문` · 🎯 목표 · **첫날 한 장**(그때 찍어 둔다) · [시작].
- 판 목표를 다 이루면 같은 틀의 끝 카드가 뜬다: **첫날 ↔ 오늘** 두 장(같은 틀로 찍음) · 새로 생긴 것을 그림으로(🏪🏪🏪 · 길은 🛣️ 세 개 + 칸 수) · 💭 `되돌아보기` · [닫기]. 한 번 닫으면 목표로는 다시 안 뜬다.
- **교사가 닫기**: 주소 끝에 `#끝`을 붙여 열면 언제든 끝 카드가 뜬다.
- 사진·첫날 물건 수는 `localStorage 'rpg.stagecard.<sid>.<id>'`에 둔다(저장본·sync 0). 자유 놀이 판(town)과 기본 판에는 카드가 없다.

## 같은 모습 잣대 (`[LK-LOOK]` · `[LK-CARD]` · PA-09 · build/D §LK)
- 수업 판(캠페인)과 유즈맵 판이 '다른 게임'이 되지 않게 — 카드 모습은 **모습 표 한 곳**(index.html 머리 `[LK-LOOK]` 의 `--vk-*` 변수)과 **카드 틀 하나**(`vcardShow`)로.
  지금 틀로 옮긴 카드 = 시작 · 끝(판 카드) · 되묻기(↺) 셋뿐이다. 나머지 막 · 카드 꼴 판(첫 안내 · ❓ 풍선 뜻 · 제목 카드 …)은 '묵은 카드' 목록(`__lookKit().묵은카드`)에 두고 옛 CSS 그대로.
- **판 검사**(`stages.mjs`): ② 캠페인 판의 `규칙`이 '조작' 스위치를 `on:false` 로 두면 FAIL(유즈맵은 REVIEW) · ③ `건물정의` 조각 색 `c` 가 팔레트 이름 · 값 · `rules.json` 의 `색허용` 밖 16진이면 REVIEW('새 색') · 모르는 이름 · `#rgb` 는 FAIL(엔진이 그 조각을 버리거나 `#fff` 를 `0x000fff` 로 읽는다) ·
  ④ 어느 등급이든 '보기' 스위치를 `on:false` 로 두면 FAIL(`rules.json` 의 `보기끔허용` — 지금 `cardDay` · `cardMap` — 만 됨) · ⑥(엔진 줄) index.html 에 position:fixed + 제 바탕(#…) CSS 가 `[LK-LOOK]` 밖 · 묵은 카드 밖에 새로 생기면 REVIEW('카드 틀을 쓰세요').
  ①(등급별 양상 걷기 · 손맛대상)은 PA-14a · ⑤(집 카드 글 words 거르개)는 W-T(PA-14a)에서. 스위치 `VRULES.lookKit`(보기) — `on: false` 면 옛 카드 꼴 · ②④ FAIL 은 REVIEW.
- '크게'(`VRULES.lookKit.big` → `:root.vk-big`): 카드 글 ×1.25 · 단추 높이 그대로 · 사진 상한 240 · 판 카드 폭 900 · 목표 줄 인라인. 켜는 길(해시 낱말)은 뒤 PR.

## `rules.json` — 규칙마다 무엇을 바꾸나 (C10)
`판정`(인구·필요·층·이사·돌아섬·일자리·붐빔 셈을 바꾼다) · `바로잡음`(원래 있던 장치를 화면 말과 맞추는 고침 — 새 장치가 아니라 세지 않는다 · growPause) · `때`(하루 합은 그대로, 시각만 옮긴다 — dayMoveIn) · `목표` · `조작` · `말` · `보기` · `연기` · `성능` · `저장·안전`.
**새 VRULES 를 넣으면 여기에 한 줄 더한다.** 빠지면 검사가 FAIL 이다.
같은 파일의 `보기끔허용`(판이 끌 수 있는 '보기' 스위치 — LK ④) · `색허용`(팔레트 밖이지만 받은 건물 색 — LK ③)도 `[LK-CARD]` 판 검사가 읽는다.
