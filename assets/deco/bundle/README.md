# 꾸미기 그림 묶음(art.json) — 스크립트가 만든 파일 · 손으로 고치지 않는다

- **무엇**: `assets/deco` · `floor` · `farm` 의 SVG 전부를 한 파일로 묶은 것(한 줄에 한 그림). 학생 화면은 꾸미기를 열 때 이 한 파일만 받는다(그림 요청 60여 건 → 1건).
- **언제 다시 만드나**: 그 세 폴더의 그림을 더하거나 고치면 `node scripts/deco-bundle.mjs` 한 번 → `art.json` 을 같이 커밋(안 하면 precheck `deco-bundle` FAIL). 묶음에서 충돌이 나면 손으로 합치지 말고 main 을 받은 뒤 스크립트를 다시 돌린다.
- **없거나 틀리면**: 화면은 예전처럼 그림을 한 장씩 부른다(깨지지 않는다) — 묶음에 없는 새 그림도 낱장 파일로 불린다.
