이모지로 안 되는 것만 여기 그림으로 둔다. **이모지로 충분한 것은 이모지로 두는 것이 낫다**(폰·크롬북에서 알아서 그려지고, 파일이 안 늘어난다).

## 이모지로 두는 것

- **🔍 검색** — 이미 9곳에서 쓰고 24px 에서도 또렷하다. 그릴 까닭이 없다.
- 🖌️ 바닥 칠하기 · ✏️ 고치기 · 🧹 지우기(공부 화면) — 지금 쓰는 그대로.

## 규격

- `viewBox 48 48`, 선 굵기 **3.2~5.2** — 24px 로 줄여도 선이 1.6px 이상이라 안 사라진다.
- **어두운 판 위**에서만 쓴다. 색은 앱에 있는 것만: 실루엣 `--txt #EFE7D9`, 흐린 선 `--txt2 #BCAB92`, 강조 하나 `--gold #D9A441`.
- `<img src>` 로 넣으면 **CSS 로 색을 못 바꾼다.** 그래서 색을 파일 안에 넣어 뒀다. 색을 바꿔 써야 하면 인라인 `<svg>` 로 넣고 `currentColor` 로 고쳐 달라고 하면 그렇게 낸다.
- 24 · 32 · 44px 에서 다 읽히는지 확인하고 넣는다(`보고_20260917\디자인2_편의성아이콘.png`).

## ⚠️ 함정 — 한 `<path>` 에 `fill` 을 두 번 주면 그림이 통째로 안 뜬다

`fill="#D9A441"` 과 `fill="none"` 이 한 태그에 같이 들어가면 **XML 오류**라 브라우저가 깨진 그림으로 그린다(선 하나만 안 나오는 게 아니라 **전체가 안 나온다**). 만들 때 `fill` 을 붙이는 자리를 갈라 두고, **만든 뒤 XML 로 파싱해 확인**한다 — 만드는 스크립트(`d2/gen_ui_icons.py`)에 그 검사가 들어 있다.
