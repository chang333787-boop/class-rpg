> 마당 꾸미기 디자인 담당 · **목록·설계(그리기 전)**. 사용자: "롤러코스터 타이쿤처럼 꽃밭 같은 것 **종류도 많았으면** 좋겠다." · "꽃 종류는 여러 개여도 되고 많아도 좋다."

### 열린 색 / 잠긴 색 — "목표에 따라 해금되는 꽃" (사용자 요청, 자리는 도감)
점수·순위·의무는 없다. **처음부터 열린 것으로도 예쁜 마당이 되고**, 모으면 **'갖고 싶은 특별한 색'**이 열린다. 전부 **같은 그림 파일 안의 팔레트**라 파일이 안 는다(#467).

| 바닥 | 처음부터 열림 | 도감으로 열림 (문턱 안) | 특별한 색 — 더 모으면 |
|---|---|---|---|
| 튤립 줄화단 | 분홍 · 노랑 | 빨강 · 흰 · 보라 · 주황 — **그 색 꽃 장식을 가진 적 있으면**(장미→빨강, 데이지→흰, 라벤더→보라, 해바라기→주황) | `#candy` 두 색 튤립(꽃·풀 8가지) · `#sherbet` 복숭아 줄(꽃·풀 12가지) · `#night` 검보라(꽃·풀 **전부**) |
| 수국 꽃 더미 | 파랑 | 보라 · 분홍 · 흰 — 물(`water`) 분류 2가지 | `#duo` 분홍+연보라(물 4가지 전부) · `#moon` 달빛 연노랑(가로등·석등을 가진 적 있으면 — "밤에 피는 꽃") |
| 들꽃 잔디 | 기본(크림·노랑·보라) | — | `#rainbow` 무지개 들꽃(동물 6가지) · `#snow` 눈꽃(나무 5가지) |

- 잠긴 색은 색 동그라미에 **작은 자물쇠 + 무엇을 모으면 되는지 한 줄**("🌹 장미를 가져 보면 열려요"). 눌러도 혼나지 않는다 — 상점의 그 물건으로 데려간다.
- 문턱은 전부 **'가진 적 있음'**(#462) — 놓지 않아도, 팔아도 다시 잠기지 않는다.
- 새 꽃 종류 밭(해바라기·라벤더·데이지·장미)이 들어올 때마다 **기본 1~2색 열림 + 나머지 잠김 + 특별한 색 1~2**를 같은 틀로.

### 그리는 순서 (한 PR 에 한 가족)
1. ✅ 꽃밭 3종(#467) → 2. **테두리 12조각 × 3재질**(꽃밭이 '화단'이 되는 순간 — 효과가 제일 크다) → 3. 바닥 무늬(클로버·낙엽·깎은 잔디) → 4. 꽃 종류 밭 4종 → 5. 칸 산울타리(코드 0) → 6. 토피어리 7종 → 7. 중심 장식.
   사이사이: 움직임 그림(#459 다음 = 캠프파이어·굴뚝 연기) · 옛 건물 3채 키우기(#462).

## 2. 서랍에서 가족끼리 묶여 보이는 순서 — `kind` 안의 작은 묶음 `group`

종류가 늘면 `plant` 탭 하나에 40개가 넘는다. **표에 `group` 한 필드**(없으면 지금 순서)를 두고, 서랍은 `kind` → `group` → 값 순으로 늘어놓는다. 묶음 사이에는 **가는 세로줄 + 작은 묶음 이름**만(탭을 또 만들지 않는다).

| `kind` | `group` 순서 |
|---|---|
| 🌷 `plant` | ①`flower` 꽃다발(장미·튤립·라벤더·데이지…) → ②`bush` 덤불·풀(낮은 관목·풀숲·갈대) → ③`topiary` 다듬은 나무 → ④`planter` 화분·화단(선인장·해바라기·큰 화단·장미 아치) → ⑤`field` 밭(밀·옥수수·보리) |
| 🌳 `tree` | ①`leaf` 잎나무 → ②`blossom` 꽃나무(벚·둥근 나무) → ③`fruit` 열매(과수나무·과수원) → ④`pine` 침엽수 |
| 🚧 `fence` | ①`wood` 나무 → ②`white` 흰 말뚝 → ③`stone` 돌담 → ④`hedge` 산울타리 — **각 묶음 끝에 그 재질의 문** |
| 🪑 `prop` | ①`seat` 벤치 → ②`light` 등 → ③`rock` 돌 → ④`farm` 상자·장작·건초·허수아비 → ⑤`center` 중심 장식(꽃시계·조각상·마법석) |
| 🏠 `building` · 💧 `water` · 🐾 `animal` | 지금처럼 값 순(수가 적다). `animal` 은 ①동물 → ②우리·먹이통 |

같은 물건의 **색 변형은 카드 하나**다 — 카드를 고르면 색 동그라미가 뜬다(아래 §3 과 같은 방식). 그래야 150가지가 서랍·바닥 고르기에서는 50장 안쪽 카드로 보인다.
