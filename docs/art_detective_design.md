## 2. 사건 하나 = 네 단계(탐정 수첩)
1. **찾기** — 그림 속 숨은 것 4~7개(차례 없이 · 겹치면 작은 곳이 먼저). 헛짚음을 세고, 두 번 헛짚으면 💡 힌트(정답보다 넓은 점선 동그라미를 살짝 비켜서 · 확대). 숨은 보너스(낙관 · 옥에 티)는 선택.
2. **생각** — 판마다 하나.
   - 단서 짚기(8판): 생각을 고르고 → 그렇게 생각한 단서를 그림에서 짚는다 → 해설('많은 사람들은 …라고 봐요' · 화가의 말) + 다른 생각의 단서도 흐리게 + 우리 반이 고른 생각.
   - 놀이 고르기(브뤼헐 「아이들의 놀이」): 해 보고 싶은 놀이를 그림에서 짚기 → 반 순위.
   - **흑백 실험**(모네 「인상, 해돋이」): 예상 → 흑백으로 바꾸기 → 해가 사라진다. 흑백은 사람 눈 밝기(L*)를 그대로 두는 변환(캔버스), 해 · 둘레 하늘 밝기를 그 자리에서 잰다(이 그림 파일로 잰 값: 해 47 · 하늘 48).
   - **색 점 세기**(쇠라 「그랑드 자트」): 강물을 크게 보고 보이는 색을 고르기 → 그 자리의 낱 점을 색 이름으로 세어 막대로(파랑 · 하양 · 초록 · 노랑 …). 3% 넘는 색이 '있는 색'.
   - **먹색 차례 재기**(정선 「인왕제색도」): 이름 붙은 네모 넷을 진한 차례로 짚기(그림 위 · 이름 단추 둘 다) → '먹색 재기' = 그 자리 낱 점의 L* 평균 → 잰 차례와 내 차례를 줄마다 ✓/✗ · 먹 연구소 먹색 다섯 가운데 가까운 이름. 틀려도 별은 그대로(실험).
   - **붓 자국 읽기**(정선 「금강전도」): 곳마다 3배 확대 → 점 · 선 · 번지기 · 마른 붓 가운데 고르기(틀린 보기는 흐리게) → 해설. 우리 반 셈 = 첫눈에 알아봄 / 한 번 더 보고 알아봄.
3. **느낌** — 느낌 칩 둘까지(신나는 · 조용한 · 쓸쓸한 …) + 까닭 하나(색 · 선 · 표정 · 몸짓 · 자리 · 빛 · 이야기) → 우리 반 셈.
4. **질문** — 그림에서 사람 · 동물 · 물건을 짚고(이름 붙은 곳) 질문 갈래를 고르면 문장이 만들어진다(조사 자동). **글 입력 없음**(학급 DB 가 열려 있어). 질문판 = 그림 위 번호 핀 + 목록 · '나도 궁금해요 ♥' · 한 그림에 셋까지.
   - 질문 사다리: 1 보이는 것(무엇을 하고 있을까 · 무엇으로 만들었을까 · 무슨 색) · 2 까닭 · 마음 · 3 상상(소리 · 다음 일 · 만약 … 없다면) · 4 화가에게(왜 이렇게 그렸을까). 선생님 화면에서 아이마다 갈래 수.
- 사건 해결 = 네 단계를 마치면. 별 = 헛짚음 + 힌트×2 (≤2 ★★★ · ≤6 ★★ · 그 뒤 ★). 해결 카드에 '그림 읽기 한마디'.

## 3. 그림 열다섯(정본 = `art/js/cases.js` · 출처 = `art/CREDITS.md`)

- 확인한 사실만 해설에: 씨름 오른쪽 아래 구경꾼의 손 좌우가 바뀜(영문 자료) · 모네 해와 하늘 밝기(직접 잼) · 쇠라 점 색(직접 셈) · 고흐 침실 오르세 1889(위키미디어 파일 설명) · 고흐 편지의 '쉼'은 첫 그림(1888)에 대한 말이라고 밝혀 둠.

## 4. 그림 보기(`viewer.js`)
- 확대 = ＋ · － · ⤢ 단추 · 마우스 휠(크롬북 터치패드 두 손가락) · 두 손가락 벌리기. 끌면 옮기기, 움직이지 않고 떼면 '짚기'(끌기는 헛짚음으로 안 셈 — 헤드리스로 확인). 최대 배율 = 그림 원래 크기의 2.2배까지.
- 표시(찾은 곳 · 단서 · 힌트 · 질문 핀)는 그림과 함께 움직이고, 선 굵기 · 글자는 배율로 나눠 늘 같은 크기.
- 찾은 곳 표시는 찾기 단계에서만(흑백 실험에서 해를 가리지 않게).

## 5. 저장(`classRPG_art` · 물감 연구소와 같은 꼴)
- `progress/<sid>/<그림>` = { st, n 헛짚음, h 힌트, t } · `stats/<sid>/<그림>` = { tries, ok, miss, hint, tmiss } · `think/<그림>/<sid>` · `feel/<그림>/<sid>` · `ask/<그림>/<id>` = { s, k 갈래, p 이름 붙은 곳, x, y, t } · `like/<그림>/<id>/<sid>` · `names/<sid>`.
- 손님(sid 없음)은 이 기기 localStorage. RPG 본 데이터 안 건드림 · 보상 없음. 선생님은 질문을 내릴 수 있음(문장이 낱말 조합이라 거의 필요 없음).
