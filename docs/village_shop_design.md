# 가게 — 대상·관계·역할 설계 한 장 (2026-09-23 · 주민 연기 담당 · **문서만 · 구현 제안 없음**)

> 보스 지시(아스트라 통합 의견 · 직접 플레이 뒤): 가게는 처음엔 **생활에 필요한 장소**, 다음엔 **무엇을 파는지 구별해야 하는 장소**, 그다음엔 **생산·운송·소비를 잇는 장소**, 또 다른 상황에선 **일터**이자 **주민의 이해관계가 만나는 장소**다.
> **순서를 지킨다**: ① 네 칸(무엇을 제공하나 → 무엇이 있어야 제공하나 → 누가 이용하나 → 누구와 어떻게 연결되나) → ② 다섯 상황마다 상태·역할·생략 → ③ **그다음에야** 있는 관계로 되는 부분과 새 관계가 필요한 부분을 가른다. 도시 요소 사전(#793)은 **③의 재료**로만 쓴다 — 그 문서는 '재사용이 되나'의 답이지 '무엇을 가르치나'의 답이 아니다(정본 설계 원칙 1).
> **이번에는 구현을 제안하지 않는다.** ③도 '무엇이 되고 무엇이 모자란가'까지만 적는다.
> 표기: ✅확인 = 지금 코드·문서로 본 것 · 💭 = 내 판단.

## 1. 네 칸 — 가게는 무엇인가 (게임 말이 아니라 세상 말로)

| 칸 | 가게 |
|---|---|
| **무엇을 제공하나** | **살림에 쓰는 물건**(먹을 것·쓸 것)을 **바꿔 가질 수 있는 자리**. 물건만이 아니다 — 가까이에 있다는 **편리함**, 사람이 오가는 **만남**, 누군가의 **일자리**도 함께 준다 |
| **무엇이 있어야 제공하나** | ① **물건** — 어디선가 만들어져 **옮겨 와야** 한다(스스로 생기지 않는다) ② **닿는 길** — 사는 사람이 걸어서(또는 타고) 올 수 있어야 한다 ③ **일하는 사람** — 물건을 받고 늘어놓고 건네는 사람 ④ **자리** — 한꺼번에 받을 수 있는 사람 수에는 끝이 있다 ⑤ (살 때) **바꿀 것** — 돈. 이 마을에는 없다(생략 · 2절) |
| **누가 이용하나** | **사는 집(세대)** 이 산다 — 집마다 필요한 양이 있고 세대가 많으면 더 필요하다. **지나가는 손님**도 들른다. **일하는 사람**은 이용하는 사람이 아니라 **돌리는** 사람이다 |
| **누구와 어떻게 연결되나** | **위로** 만드는 곳(밭·부두·벌목장·공장) — 물건이 **길을 따라 옮겨져** 온다. **옆으로** 다른 가게 — 같은 것을 파는지 다른 것을 파는지. **아래로** 사는 집 — 가까운 집이 먼저, 먼 집은 못 온다. **둘레로** 이웃 — 가게 앞은 붐비고 쓰레기가 나고 밤에 불이 켜진다. **마을 전체로** — 어디에 몇 개를, 언제까지 열지 **함께 정할 일**이 된다 |

💭 이 네 칸에서 벌써 다섯 상황이 나온다: '제공'이 **생활시설**을, 물건의 **종류**가 **물건의 종류**를, '있어야'의 ①이 **생산·소비**를, ③이 **일과 생활**을, '둘레·전체'가 **공동 결정**을 부른다. 상황은 새로 지어낸 것이 아니라 **한 가게의 서로 다른 칸을 앞에 세운 것**이다.

## 2. 다섯 상황

**모든 상황의 공통 상태**(가게가 어느 판에 있든 늘 있는 것): **있다/없다 · 어디에 있나 · 어느 집에서 길로 닿나(가깝다/멀다) · 누가 오나.**
아이의 **기본 역할**은 어느 판이든 **'마을을 가꾸는 사람'**(무엇을 어디에 놓을지 정한다)이다 — 보스가 든 넷(주민·소비자·운영자·공동 결정 참여자)은 이 위에 **판마다 하나씩 얹는 역할**이다. 💭 이 구분을 적어 두지 않으면 "지금 게임은 역할이 없다"와 "지금 게임은 전부 배치다"가 같은 말이 된다.

### 상황 ① 생활시설 — "장 볼 곳이 가까워야 산다"

| | |
|---|---|
| 추가 상태 | **닿음 / 멂**(집마다) · 멀어서 **새 이웃이 돌아섬** |
| 역할 — 나는 누구 · 무엇을 결정하나 | **주민의 필요를 보는 사람**(기본 역할 그대로) · 결정: **어디에** 가게를 둘까 · 길을 어떻게 이을까 |
| 아이의 행동 | 멀다는 집을 눌러 까닭을 읽는다 → 가게를 옮기거나 더 놓거나 길을 잇는다 → 돌아서던 집에 사람이 드는지 본다 |
| 생략한 것 | 물건(늘 충분하다고 **가정**) · 종류(가게는 다 같다) · 돈 · 영업 시간 · 붐빔 |
| 설명 두 문장 | 이전: "가게가 **있어야** 장을 본다" → 이번: "가게가 **닿아야** 장을 본다 — 있어도 먼 집은 못 온다" |

### 상황 ② 물건의 종류 — "무엇을 파는지 구별한다"

| | |
|---|---|
| 추가 상태 | 가게마다 **무엇을 파나**(빵 · 채소 · 문구 …) · 집마다 **무엇이 필요한가** · 이 집이 필요한 것을 **어느 가게에서** 구하나 |
| 역할 | **소비자**(고른다) — 결정: 이 집은 **어느 가게에 갈까**(가까운 곳? 필요한 것을 파는 곳?) · 또는 기본 역할로 **어떤 가게를 열까** |
| 아이의 행동 | 가게를 눌러 파는 것을 본다 → 필요한 것과 파는 것을 견준다 → 빠진 종류를 알아채고 그 가게를 연다 |
| 생략한 것 | 값·돈 · 한 가게 안의 여러 물건(한 가게 = 한 종류로 **가정**) · 품질 · 광고 |
| 설명 두 문장 | 이전: "가게가 닿으면 장을 본다" → 이번: "닿아도 **필요한 것을 파는** 가게여야 한다 — 가게마다 하는 일이 다르다" |

### 상황 ③ 생산·운송·소비 — "물건은 어디서 오나"

| | |
|---|---|
| 추가 상태 | 선반에 **물건이 있다/비었다** · 빈 까닭(오는 중 / 길이 끊김 / 만드는 곳이 없음 / 아직 모자람) · 운반 중인 짐 · 집마다 **오늘 몫을 받았나** |
| 역할 | **운영자**(생산·주문을 맞춘다) 또는 기본 역할 — 결정: 만드는 곳을 **어디에 몇 곳** · 길을 **어떻게** 이을까 · (운영자라면) 어느 만드는 곳에서 **얼마나** 받을까 |
| 아이의 행동 | 빈 선반을 누른다 → 까닭을 읽는다 → 까닭의 **자리**(끊긴 길 · 모자란 밭)로 간다 → 바꾸고 → 수레가 닿아 선반이 차는 것을 본다 |
| 생략한 것 | 돈·값 · 주문(물건은 **가까운 가게부터 저절로** 간다) · 창고·보관 기간 · 물건이 상함 · 한 가지 물건만(**가정**) |
| 설명 두 문장 | 이전: "가게에 가면 물건이 있다" → 이번: "가게의 물건은 **다른 곳에서 만들어져 길로 옮겨 온다** — 만드는 곳이나 길이 끊기면 가게가 빈다" |

### 상황 ④ 일과 생활 — "가게는 누군가의 일터다"

| | |
|---|---|
| 추가 상태 | 가게에서 **일하는 사람 수**(자리 몇 개 중 몇) · 집마다 **일할 곳이 닿나** · 가게를 치우면 **일자리도 사라진다** |
| 역할 | **주민**(일하러 가는 사람) 편에서 보기 — 결정은 기본 역할: 일터를 **집에서 닿는 곳에** 둘까 |
| 아이의 행동 | '일할 곳이 멀어요' 집을 누른다 → 가게·온실 같은 일터를 그 집 가까이 놓는다 → 문 밖에서 일하는 사람을 본다 |
| 생략한 것 | 임금·돈 · 직업의 높낮이(교과 지도의 약속: **직업 서열 없음 · 골드로 바꾸지 않음**) · 일하는 시간의 길이 · 아이 주민은 일하지 않음 |
| 설명 두 문장 | 이전: "가게는 물건을 사는 곳이다" → 이번: "가게는 **누군가 일하는 곳**이기도 하다 — 가게 하나가 여러 집의 살림을 받친다" |

### 상황 ⑤ 공동 결정 — "가게는 이해관계가 만나는 곳이다"

| | |
|---|---|
| 추가 상태 | 가게 곁 **붐빔 · 쓰레기 · 밤 소란** · 누가 **편해지고** 누가 **불편해지나**(가까운 집 · 먼 집 · 가게 앞 집) · 정한 것이 **언제·어디에** 걸리나 |
| 역할 | **공동 결정 참여자** — 결정: **제안하고 · 견주고 · 정하고 · 다시 본다**(새 가게 자리 · 문 닫는 시각 · 가게 앞 쓰레기 약속) |
| 아이의 행동 | 가게 앞 불편을 알아챈다 → 두 안을 미리 보고 견준다 → 하나를 정한다 → 영향받은 집의 반응을 보고 다시 본다 |
| 생략한 것 | 가게 주인의 이익(돈) · 투표 수 셈 · 법의 강제 · 여러 사람이 실시간으로 함께 정하기 |
| 설명 두 문장 | 이전: "가게는 가까울수록 좋다" → 이번: "가게가 가까우면 **편한 집과 불편한 집이 함께 생긴다** — 그래서 어디에·언제까지를 함께 정한다" |

**다섯을 한 줄로** 💭: ①은 **닿음**, ②는 **종류**, ③은 **흐름**, ④는 **일**, ⑤는 **이해관계**다. 한 판은 **하나를 앞에 세우고**, 나머지는 '생략한 것'에 **가정으로 적는다**(정본 설계 원칙 5 · 판 카드 18칸).

## 3. 그다음에 — 있는 관계로 되는 부분 / 새 관계가 필요한 부분

**지금 가게가 이미 하는 것** ✅확인(main `1b38572`):
- **필요 `장보기`** — 집에서 **길로 14칸**(큰길에 붙으면 20칸) 안이면 닿는다. 멀면 걱정 풍선 · 새 이웃이 돌아섬.
- **일자리 4** — 집 단위 배정(반경 40칸) · 문 밖에서 상자를 정리하는 일꾼(ACT-WORK).
- **흐름의 받는곳** — 선반 양 · 빈 선반의 **까닭 값 넷**(coming·cut·none·growing) · 접힌 차양·팻말 모습 · 누르면 끊긴 칸으로 데려가기 · 장바구니를 든 주민이 나옴 · 수레가 싣고 옴(#827).
- **수용량** — `정원` 이 적힌 가게만(도시 판 상가 6). 자리를 못 얻은 집은 「가게가 꽉 차서」. 판이 `끄기` 로 멈춘다. ⚠ 그 **뜻**(하루 처리 능력인가, 지속 배정인가)은 아직 안 골랐다(#810 고쳐 둠).
- **둘레** — 가게 곁 쓰레기(litter) · 비 오면 처마 밑에서 비를 피함 · 칭호 '북적이는 장터 마을'의 한 칸 · 목표 '가게 하나 열기'.
- **공동 결정 쪽** — 가게를 대상으로 한 결정은 **없다**. 정치 층 문서에 후보만 있다("가게는 해 지면 문 닫기" · "가게 문 닫는 때 — 일터는 좋지만 이웃에 치르는 것이 있다").

| 상황 | 있는 관계로 되는 부분 | 새 관계가 필요한 부분 | 💭 |
|---|---|---|---|
| ① 생활시설 | **거의 전부** — 필요 `장보기` · 거리 14칸 · 돌아섬 | 없음 | 지금 엔진이 가장 잘 하는 자리. 다만 '물건은 늘 있다'는 **가정을 판에 적어야** ③으로 이어진다 |
| ② 물건의 종류 | 가게를 여러 종류로 **그리는 것**(판 파일 `건물정의`) · '빵집' 같은 이름 | **"이 집은 무엇이 필요한가"와 "이 가게는 무엇을 파는가"를 잇는 것** — 지금 필요는 `장보기` **하나**다. 가게가 둘이어도 둘 다 같은 필요를 채운다. 도시 요소 사전의 '백화점 = 한 곳에서 여러 필요(need2)'는 **한 건물이 여러 필요를 채움**이지, **종류를 가려 고름**이 아니다 | 사전이 '새 관계 0'으로 읽은 자리 가운데 교육적으로 **가장 모자란** 곳이다 — 종류가 없으면 **소비자 역할(고르기)이 설 자리가 없다** |
| ③ 생산·소비 | **흐름 전체**(만드는곳→길→받는곳→세대 · 까닭 넷 · 데려가기 · 수레) · 물건 이름을 판마다(생선·통나무 #816) | **운영자 역할의 결정**(어디서 얼마나 받을까) — 지금 물건은 **가까운 가게부터 저절로** 간다. 아이가 정할 것이 '배치'뿐이다. 물건이 둘 이상이면 ②와 같은 모자람이 여기서도 나온다 | 배치로 가르칠 수 있는 것('끊기면 빈다')은 이미 선다. **'고르고 맞추는' 것은 없다** |
| ④ 일과 생활 | 일자리 4 · 집 단위 배정 · 일할 곳이 먼 집 · 문 밖 일꾼 | 없음(임금·직업의 높낮이는 **일부러** 뺀 것) | 되지만 **가게만의 것이 아니다** — 온실·풍차·부두도 같은 관계다. '가게가 사라지면 일자리도 사라진다'가 **가게 판의 장면으로** 보이는지는 따로 봐야 한다 |
| ⑤ 공동 결정 | 공동 결정 **틀**(프로토 `proto-vote` — 미리 보기·적용·되돌리기 · 판정 0) · 둘레 현상(쓰레기·붐빔)은 이미 셈이 있다 | **가게에 거는 결정의 대상** — 문 닫는 시각(가게가 '언제 여나'라는 상태가 지금 없다) · 가게 앞 약속. 결정이 **누구에게 어떻게 닿나**를 가게 쪽에서 셀 자리 | 틀은 있고 **가게 쪽 손잡이가 없다**. 우물 자리 정하기(프로토)와 달리 '어디에'가 아니라 '**언제·어떻게**'를 정하는 결정이다 |

**가른 결과** 💭: 사전의 결론("새 관계는 세대 하나")은 **①·④ 에서만 맞다.** ②·③·⑤ 에서는 그리는 것은 되지만 **아이의 역할(고르기 · 맞추기 · 함께 정하기)이 설 관계**가 없다. 모자란 것은 건물이 아니라 **역할이 결정할 대상**이다.

## 4. 이 방식이 학교·공공시설에도 서나 (가볍게 대 보기)

| 칸 | 학교 | 공공시설(도서관·보건소·공원) |
|---|---|---|
| 무엇을 제공하나 | 배움 · 아이들이 함께 있는 자리 | 누구에게나 여는 쓰임(책·건강·쉼) |
| 무엇이 있어야 | 선생님(일자리) · 닿는 길(통학로) · 자리 | **마을이 함께 세우고 돌리는 것**(주인이 마을이다) · 닿는 길 |
| 누가 이용하나 | 식구 가운데 **아이** | 모든 주민 — **돈을 내지 않고** |
| 누구와 연결되나 | 집(등굣길) · 도서관 · 마을이 커지면 한 곳으로 모자람 | **공동 결정**(가게는 사람이 많으면 '저절로' 늘 수 있어도 공공시설은 **마을이 정해야** 생긴다 — 정치 층 문서) |

- **네 칸은 선다.** 다섯 상황 가운데 ①(생활시설)·④(일과 생활)·⑤(공동 결정)는 그대로 옮겨진다.
- **②·③은 시설마다 바뀐다** 💭 — 학교에서 ②는 '무엇을 파나'가 아니라 '무엇을 배우나(초·중)'이고, ③은 **물건의 흐름이 아니라 사람의 흐름**(등굣길 · 통학)이다. 그러니 다섯 상황은 **가게의 목록**이지 모든 시설의 틀은 아니다. 틀로 옮겨지는 것은 **네 칸과 '역할을 먼저 정한다'** 두 가지다.
- 공공시설은 **⑤가 앞에 선다** — 가게는 ⑤가 마지막 상황이었지만 공공시설은 '누가 세우나'부터가 공동 결정이다.

## 5. 이 문서가 하지 않는 것

- 구현 제안 · 새 VRULES · 판 파일 · 수치. (보스 지시 5)
- 다섯 상황의 **순서**를 수업 순서로 정하는 것 — 교과 지도가 정할 일이다.
- 수용량의 뜻 고르기(#810 고쳐 둠에 남은 물음) — ①과 ⑤ 사이에 걸려 있다는 것만 적는다: '한꺼번에 받을 사람 수에 끝이 있다'는 **①의 '있어야' 칸 ④**다.
