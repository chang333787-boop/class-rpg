## 엔진
1. 사진 읽기(`createImageBitmap` EXIF 회전 반영) → 긴 변 800px 축소본
2. 테두리: 밝기 블러 → Otsu 이진화를 **두 번**(그대로 / 채도 낮은 곳만 = 흰 종이) → 가장 큰 덩어리 → 볼록 껍질 → 넓이 최대 사각형 → "네모다움" 점수(껍질 채움·덩어리 채움·각도·화면 끝 붙음) 0.55 미만이면 실패 → 안쪽 10% 사각형을 손잡이로
3. 원근 보정: 4점 호모그래피, 원본(긴 변 2400px)에서 역매핑·쌍선형, A4 비율 ±8%면 A4로, 긴 변 1600px
4. 스캔 필터: 1/8 축소 → 이웃 최댓값(글씨 무시) → 블러 = 조명 → 나누기(그림자 평탄화) → 2%/90% 구간 펴기 + S자 곡선. 흑백(기본)·컬러·보정만
5. JPEG 0.85부터 낮춰 ≤500KB, 넘으면 80%로 줄여 다시
- 폴백: 손잡이 4개(48px) 끌기 + 돋보기, "테두리 다시 찾기", "보정만"
- iframe 안이면 결과 Blob을 `postMessage({type:'scan-result'})`로 부모에 넘김(연결 PR에서 작품 올리기 폼이 받음)
