# 2026-09-20 — 맥북 · 마당 꾸미기 프로그램 담당 3대 · **마당 안 상점**(DECO-SHOP-1)

> 화면 규칙 = `docs/deco_shop_home_screens_20260920.md` ①(A안 "탭 하나 더"). 버스터 `mcm`. 머지는 주말 보스.

## 1. 무엇을 넣었나
- 서랍 머리에 `[🎒 내 것 | 🛒 상점]` 탭 · 골드 배지(HUD `.badge.gold` 값 그대로) · 상점 탭에서만 분류 칩 한 줄 + 사기 막대.
- 상점 카드는 **🛒 를 처음 누를 때** 만든다(꾸미기를 여는 값 0 · 요청 수 81 → 81).
- 카드 상태: 살 수 있음 / 골드 부족 / (레벨 잠금) / 도감 선물 / 골라짐. 죽은 카드는 없다 — 눌러서 구경하고, 막대가 까닭을 말한다.
- 200G 미만 = `[사서 놓기 ▶]` 한 번 · 200G 이상 = `[한 번 더 눌러 사기]`(두 번 두드림 0.35초는 한 번으로) · 무료 기간 = `🎁 무료` + 원래 값 취소선, 한 번에.
- 산 직후 = 내 것 탭 · 그 카드가 맨 앞에 골라진 채 · 손끝 그림(마우스는 따라다니고 터치는 마당 가운데에서 기다림) · 하나 놓으면 끝.

## 2. 🔴 골드 — 사는 길은 하나
- `decoShopBuy()` 는 **본편 상점의 `buyDeco(id)` 를 그대로 부른다**(값 `decoCost` · 무료 기간 · 골드 차감 · 인벤토리 +1 · `DB.saveStudent` · `DB.logSpend` 전부 그 함수). `buyDeco` 는 한 글자도 안 고쳤다.
  `buyDeco` 의 '한 번 더 누르면 사요'(3초) 걸음은 사기 막대가 이미 받았으므로 `_buyDecoArm` 을 미리 채워 통과시킨다.
- ⚠️ 알아 둘 것: **`buyDeco()` 자체에는 '살 수 있나' 검사가 없다.** 본편 상점은 살 수 없는 것을 *카드를 안 그려서* 막는다
  (`price>0 && !hidden` · 레벨 잠금은 카드의 onclick). 값 0 인 도감 선물·숨긴 장식도 그 함수 안에서는 막히지 않는다 → **부르는 쪽이 막아야 한다.**
  마당 안 상점은 `_decoShopState(d) === 'ok'` 일 때만 부른다(숨김·업적 보상·도감 선물·레벨 잠금·다른 장소 것·골드 부족은 전부 막힘 — 하네스 ⑯).
- 저장: 구매 1번 = 통째 저장 1번(본편과 같다). 꾸미기 묶음 저장(0.4초)이 대기 중이면 그 변경은 구매 저장에 실려 가므로 **대기만 푼다**(`decoSaveAbsorbed()` · 쓰기 0).
  `decoFlush()` 를 먼저 부르면 저장이 2번 나간다 — 같은 결과에 쓰기만 는다.

## 3. ↩ 환불은 **넣지 않았다** — 까닭
화면 규칙 ①-4-5 는 "놓기 전에 ↩ 하면 골드 +값"이다. 골드가 늘어나는 길이 생겨서 뺐다.
1. 이 앱은 다른 곳에서 변경이 올 때마다 `CUR` 을 **서버 값으로 통째 교체**한다(`DB.onDataChange`). 구매 저장이 서버에 안 남은 채(교사 쪽 통째 저장이 덮음 = #288 · 저장 거절) `CUR` 이 구매 전으로 돌아가도 되돌리기 기록은 기억에 남아 있다 → ↩ = **원래 갖고 있던 장식 1개를 산 값 그대로 골드로 바꾸는 길.** 무료 기간에 0G 로 받은 장식이 450G 가 된다. '가진 수가 산 직후와 같을 때만' 같은 조건으로 좁힐 수는 있어도 닫히지는 않는다.
2. 지출 기록 `DB.logSpend` 는 0 이하를 버린다 — 환불을 기록할 길이 없어 '쓴 골드' 통계가 어긋난다(고치려면 gamedata.js 의 골드 기록을 건드려야 한다 = 구역 밖 · 고위험).
3. 되돌리기(DECO-UNDO-1)의 약속이 "골드는 건드리지 않는다"이고 하네스가 그것을 지킨다(`어떤치우기에도_골드불변`).
→ 알림 글에서 "(↩ 되돌리면 골드도 돌아와요)"를 뺐다. 실수 막기는 '카드 고르기 → 단추'(두 번) · 200G↑ 는 세 번으로.
→ 넣으려면 먼저: 골드 되돌림(#288) 해결 + `logSpend` 에 환불 경로. 그 뒤 `{t:'buy', id, cost, qtyAfter}` 한 줄이면 된다.

## 4. 화면 규칙과 다르게 한 것
- **도감 선물 카드는 꺼 두었다**(`DECO_SHOP_GIFTS = false`). 표 주석대로 "도감 코드가 붙기 전엔 아무도 못 받는다" — 지금 "도감을 채우면 받아요"를 보여 주면 받을 길 없는 약속이다(아이가 다듬은 나무 5가지를 사도 아무 일도 안 생긴다). 상태·막대·회색 그림은 다 만들어 두었고 하네스가 켜고 본다. 도감 PR 이 이 스위치를 켠다.
- **분류 칩의 kind**: 표에 `kind` 가 있는 것은 7종뿐(다듬은 나무). 나머지는 `docs/deco_place_table.md` 의 kind 를 student.js 의 작은 목록(`_DECO_KIND_OLD`)으로 옮겼다 — 표에 kind 가 다 들어오면 지운다. 집 안에서는 칩이 `전체 · 🛋️ 가구 · 🖼️ 장식`.
- **레벨 잠금** 상태를 하나 더 두었다(본편 상점과 같게 — 지금은 전부 Lv1 이라 안 보인다).
- 상점은 **지금 장소(마당/집 안)에 놓을 수 있는 것만** 보여 준다('사서 놓기'가 바로 되게). '이 장소만' 칩은 상점 탭에서 숨는다.
- 사기 막대의 ✕ 는 늘 있다(규칙 표는 200G 미만에 ✕ 가 없다).
