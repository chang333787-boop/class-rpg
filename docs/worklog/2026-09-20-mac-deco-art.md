## 주의 / 미해결
- **장식 SVG 와 bbox.json 에는 버스터가 없다**(`./assets/deco/<id>.svg`, `fetch('./assets/deco/bbox.json')`). 그림을 바꿔도 캐시가 남은 기기는 옛 그림을 본다. 이번 두 PR 은 모양이 거의 같아 티가 안 나지만, 크게 바꾸는 그림은 보스가 방법을 정해야 한다(#417 에서도 같은 메모).
- 점검 도구는 세션 임시 폴더에 있어 사라진다. 다시 만들 때 요점: ① SVG 를 **data URI 로 끼운** html 을 헤드리스 크롬으로 찍는다(file:// 그림은 캔버스가 오염돼 픽셀을 못 읽는다) ② 페이지 폭은 body 에 고정값을 주고 `--window-size` 높이는 `--dump-dom` 으로 먼저 읽는다(worklog 09-10 의 뷰포트 함정) ③ 끝 닿음은 진한 것(알파>200)과 옅은 것(알파>8)을 **따로** 센다 — 옅은 것만 닿으면 그림자다.
- 저장소 밖에 `우리반RPG/보고_20260919/` 폴더를 만들었다(시트 PNG 20장). 학교의 `보고_YYYYMMDD` 와 같은 용도.
- 학교 그림 세션이 같은 파일(d_y9 · d_y12 · d_y19 · d_y21 · d_y23 · d_y35 · bbox.json)을 월요일에 만지면 충돌한다 — 위 두 PR 머지 여부를 먼저 볼 것.
