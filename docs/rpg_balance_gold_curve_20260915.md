## 구조 제안 (B-2 방식)
1. **B-2d(출력 동일)**: 골드도 몬스터 능력치처럼 `BALANCE.monsterGold = { base:{a,b}, rarity:{…} }` + 몬스터 줄의 **보정**(= 지금 값 − 곡선값)으로 옮긴다. identity 대조표 24줄 ✅ 로 아이가 보는 값 0 변화 증명.
2. 그다음 결정은 **"어느 보정을 0으로 할지"** 한 가지로 줄어든다: 11종만 0 → G2 / 전부 0 → G1 / 그대로 → G0.
