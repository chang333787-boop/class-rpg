# 창조자의 눈 — 프로토타입 둘(고장·정치) 관찰 계획 (2026-09-21)

> 정본: `docs/village_proto_spec.md`(#753). 이 문서는 **프로토타입이 열리면 그대로 쓸 관찰 계획**이다.
> 나는 **코드를 고치지 않는다.** `?sid=guest` · 시험 저장 공간만 · 본편 저장본과 운영 데이터에 붙지 않는다.
> 보고는 **사실 / 해석 / 가설**을 줄마다 갈라 적고, 고칠 것 목록은 12회처럼 **ⓐ 멈추고 고칠 것 / ⓑ 이번 묶음 / ⓒ 아이 사용에서 확인할 것**으로 나눈다(보스가 다르게 원하면 그대로 맞춘다).

## 0. 먼저 적어 두는 한계 — 이 관찰이 **증명하지 못하는 것**

- 내가 과제를 풀어내도 그것은 **"조작과 설명 경로를 통과했다"** 까지다.
- **초등학생이 단위 전환(마을 ↔ 마을 묶음)을 이해한다는 결론은 실제 학생에게 확인할 일**이다. 이 기록에 '학습 검증'이라고 쓰지 않는다.
- ⚠ **나는 이미 정본을 읽어서 원인 셋(공급원 없음 · 연결 단절 · 운송 중)을 안다.** 처음 보는 아이의 헤맴을 그대로 재현할 수 없다. 그래서 아래 1-1 의 **'손대지 않고 먼저 보기'** 와 **'짐작 먼저 적기'** 로 아는 것을 쓰는 순간을 표시한다. 그래도 남는 편향은 ⓒ(아이 사용에서 확인)로 넘긴다.
- 화면을 도구(훅)로 읽는 것은 **내 확인용**이고, 아이는 그 값을 못 본다. 두 가지를 섞어 쓰지 않는다 — **아이가 본 것**과 **실제 상태**를 따로 적는다.

## 1. 고장 프로토타입

보스가 준 과제 셋만 들고 들어간다(해결 순서는 안 받았다).
**① 빈 가게에 물건이 안 오는 까닭을 찾는다 → ② 관련 장소를 찾아 한 가지를 바꾼다 → ③ 왜 풀렸는지 설명한다.**

### 1-1 관찰 절차 (한 회마다 이 순서 그대로)

| 단계 | 하는 일 | 남기는 것 |
|---|---|---|
| **0. 손대지 않고 보기** | 첫 화면에서 **30초 동안 아무것도 누르지 않는다** | 보이는 것만 받아 적기 · "다음에 무엇을 눌러야 할지" 첫 짐작 한 줄 · 화면 사진 |
| **1. 짐작 먼저** | 누르기 **전에** "지금 내 짐작"을 한 줄 적는다 | 짐작 → (나중에) 실제. 틀린 짐작은 **그때 화면이 뭐라 했는지**와 함께 |
| **2. 한 번에 한 가지** | 과제 ②는 **딱 한 가지만** 바꾼다 | 무엇을 · 어디서 · 왜 그것을 골랐는지 |
| **3. 대조** | 화면 말 ↔ 실제 상태(훅·재고 값) | 어긋나면 **어긋난 지점**으로 따로 |
| **4. 설명** | 과제 ③을 **화면에 있는 말만으로** 써 본다 | 화면 말로 안 되면 어디서 막혔는지 |

### 1-2 기록할 세 가지 (클릭 수는 안 센다)

1. **잘못 짚은 까닭** — 내가 틀리게 짐작한 것 하나하나 + 그렇게 짐작하게 만든 **화면의 말/그림**.
2. **길을 잃은 화면** — "다음에 뭘 눌러야 할지 모르겠다"가 된 지점. 화면 이름 · 그때 화면에 있던 단서 · 내가 실제로 한 행동.
3. **설명과 실제가 어긋난 지점** — 화면이 한 말 ↔ 상태 값. (12회 ⓐ처럼 "이어졌어요"인데 실제로는 안 이어진 종류.)

### 1-3 세 원인을 **구분해서** 보이는가 (정본 2-3)

각 상태에서 **가게를 눌렀을 때 뜨는 말**과 **고장 화면의 표시**를 표로 나란히.

| 상태 | 가게 카드 말 | 고장 화면 표시 | 출발지 재고 | 아이가 둘 한 수 |
|---|---|---|---|---|
| 공급원 없음 | | | | |
| 연결 단절 | | | | |
| 운송 중 | | | | |

- 잣대(9회 '자리 vs 거리'와 같다): **세 상태의 말이 서로 다른가** · 그 말이 **가리키는 곳으로 갈 수 있는가**('공급 경로 보기'가 실제로 그 연결을 짚는가) · **한 수로 풀리는가**.
- 셋 중 둘이 같은 말이면 그 자리는 ⓐ/ⓑ 후보다.

### 1-4 화면 왕복·시간 (정본 2-2)

- 고장 ↔ 마을 A ↔ 마을 B 를 오가며 **재고 숫자가 이어지는지**, **시간이 같이 흐르는지** 확인. 같은 값을 두 화면에서 읽어 나란히 적는다.
- 되돌아왔을 때 **화면이 처음 상태로 되돌아가 있지 않은지**(카메라·선택·강조 포함).

### 1-5 물건이 설명 없이 생기거나 사라지지 않는가 (정본 2-4)

- 끊고 → 잇는 동안 **출발지 재고 + 운반 중 + 도착지 재고**를 시각마다 적어 **합이 맞는지** 본다.
- 저장 → 다시 열기(정본 D) 뒤 같은 합을 다시 적는다. 어긋나면 **숫자와 시각을 그대로** 보고한다(해석 없이).

### 1-6 화면 증거 (정본 7④)

**원인 전 · 문제 상태 · 복구 후** 세 장을 원인 셋마다. 주민 이름이 화면에 나오면 그 장면은 빼거나 이름 없는 각도로 다시 찍는다.

## 2. 정치 프로토타입

순서: **A안 미리 보기 → B안 미리 보기 → 하나 적용 → 다시 살펴보기(되돌리기) → 다른 안 적용.**

### 2-1 보스가 말한 두 가지를 이렇게 잰다

**㉠ 같은 결정이 사람마다 다른 결과를 낳는 것이 '비교되어' 보이는가**

| 볼 것 | 어떻게 |
|---|---|
| 두 안을 **나란히** 볼 수 있나 | A안을 보는 동안 B안의 값이 화면에 남아 있는가. 한 번에 하나만 보이면 아이는 **기억으로** 비교해야 한다 — 그 사실을 적는다 |
| 누가 가까워지고 누가 멀어지는지 | 두 동네 주민이 **각각** 표시되는가(합계 하나로 뭉뚱그리지 않는가) |
| 미리 본 것과 적용 결과가 같은가 | 미리 보기 값 ↔ 적용 뒤 값(훅·카드)을 숫자로 나란히 |
| 이유가 보이는가 | 두 동네 의견 카드가 **자리 차이와 이어지는 말**인가, 그냥 찬반인가 |

**㉡ 남은 불편이 감춰지지 않는가**

| 볼 것 | 어떻게 |
|---|---|
| 적용 직후 화면 | 뜨는 말 가운데 **좋아진 쪽 문구 수 ↔ 남은 불편 문구 수**를 센다 |
| 멀어진 주민 | 그쪽 동네 카드·주민 말이 **같은 크기·같은 자리**로 남는가, 작게/나중에 나오는가 |
| 승패로 처리하지 않는가(정본 3) | 총점·정답·축하 연출이 있는가 |
| 되돌린 뒤 | **앞 실행의 흔적**이 말·강조·카메라에 남는가 |

### 2-2 되돌아보기 세 질문(정본 3)

화면에 실제로 있는지, 있다면 **아이가 화면 값만으로 답할 수 있는지**를 질문마다 ○/△/✗ 로.
① 어떤 이유로 골랐나 ② 누가 편해지고 누구의 불편이 남았나 ③ 다시 살펴볼 점은.

### 2-3 화면 증거

A안 미리 보기 · B안 미리 보기 · 적용 후 · 되돌린 후 네 장.

## 3. 보고 틀 (프로토타입별로 한 장)

정본 7 의 여섯 칸을 그대로 쓰되, ③④ 안에서 줄마다 갈라 적는다.

1. **실행 경로** — 어디서 어떻게 열었나(보스가 준 경로 그대로)
2. **해 볼 행동** — 내가 누른 순서
3. **완료 시험 통과/실패와 실제 결과** — 정본 2-5 / 3 의 시험 이름과 실제 값
4. **화면 증거** — 원인 전 · 문제 상태 · 복구 후
5. **미검증** — 실제 학생 이해 · 실기기 · 내 사전 지식 편향(0 항)
6. **본편 반영 판단** — 가져갈 것 · 버릴 것 · 결정이 필요한 것

각 발견은 세 줄로:
- **사실**: 화면에 뜬 말 · 훅이 돌려준 값 · 숫자(해석 없이)
- **해석**: 그 사실이 무엇을 뜻한다고 보는지(내 판단이라고 밝힘)
- **가설**: 아이가 이럴 것 같다 — **확인은 실제 아이 사용에서**

고칠 것 목록은 **ⓐ 멈추고 고칠 것 / ⓑ 이번 묶음 / ⓒ 아이 사용에서 확인**.

## 4. 내가 준비해 둔 것 / 보스에게 필요한 것

- 준비됨: 관찰 틀(가려진 창에서도 시간이 흐르게 하는 서빙 틀) · 진짜 마우스·터치 조작 · 화면 사진 저장 · 훅으로 상태 읽기.
- 열릴 때 **보스에게 받아야 할 것**: ① 진입 경로(주소·버튼) ② 시험 저장 공간 이름(본편 저장본과 다른 키) ③ 프로토타입에서 쓸 수 있는 훅 이름 ④ **정본에 적힌 '쓴 값과 단위'**(생산량·사용량·운송 시간) — 그 값을 알아야 "설명과 실제가 어긋난다"를 셀 수 있다.
- 첫 회는 **고장 먼저**(과제 셋), 그다음 정치. 한 회에 둘을 섞지 않는다.
