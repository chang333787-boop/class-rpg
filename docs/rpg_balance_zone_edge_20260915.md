# 사냥터 경계(Lv10→11) 설계안 (2026-09-15)

> 밸런스팀 후보 3차 ③. **설계·시뮬 표만 — 데이터·화면 문구 변경 0, 결정은 사용자.** 운영 설정(×1.5/1.6), 물리 풀장비, 사냥터 카드는 게임의 `generateBattleOffers` 그대로 150회 × 몬스터별 60판.

## 무엇이 문제였나 (#307)
레벨 평균 골드가 Lv10 60G → Lv11 35G 로 떨어진다. 원인은 골드 값이 아니라 **구성**: 초급 Lv10 = rare 2 · legend 1, 중급 Lv11·12 = **common 5종씩**.

- 중급 사냥터는 Lv1 부터 열려 있어(`minLv:1`) 아이가 사냥터를 고른다. **역전은 Lv11 한 레벨뿐**(Lv12 비슷, Lv13부터 중급이 확실히 이득).
- 그래서 체감 문제는 작다 — Lv11 에 머무는 며칠 동안 "초급이 더 준다".

## 따로 발견 — 사냥터 카드 문구가 실제와 다르다 (학생 화면)
`student.js` 사냥터 카드: **"10G / 마리 · 18G / 마리 · 32G / 마리"**. 실제 몬스터 골드 평균은 **초급 29G(18~60) · 중급 52G(35~110) · 고급 106G(70~220)** — 옛 밸런스 값이 문구에만 남음. 데이터에서 범위를 계산해 보여주면 틀릴 일이 없다. **student.js 는 다른 세션 영역 — 보스에게 넘김.**
