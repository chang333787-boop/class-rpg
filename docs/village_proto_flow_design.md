# 고장 프로토타입 — 설계 한 장 (2026-09-21 · **문서만 · 구현 전**)

> 정본 `docs/village_proto_spec.md` 2절. 답할 질문: **"마을을 작게 묶어 보여 줘도 아이가 물건이 어디서 와서 어디에 쓰이는지 따라가 고칠 수 있는가."**
> **버릴 셈으로 만드는 시험**이다. 2-4가 요구한 다섯 물음에 답하고, 기존 흐름(#745~#754)에 이미 정한 것은 **"그대로"**라고 적는다.

## 0. 가장 큰 결정 — 계산은 한 세계 그대로, '마을'은 화면일 뿐

정본의 ⚠ 제약: **'줌 단계 = 단위 단계'는 가설이므로 내부 계산을 마을 단위로 다시 만들지 않는다.**

그래서 이렇게 한다:

- **한 판(한 세계)** 안에 두 동네를 **멀찍이 미리 배치**한다(시작 저장본). 사이는 긴 길 하나로 잇는다.
- 계산은 **지금 흐름 그대로** — 밭 → (길 BFS · 거리 × 칸당틱) → 가게 → 세대. 마을 집계·마을 재고 같은 새 단위를 **만들지 않는다**.
- '마을 A / 마을 B / 고장'은 **카메라 자리와 요약 카드**다. 화면을 바꿔도 **같은 세계·같은 시간**이 흐른다(정본 2-2 요구가 저절로 충족된다 — 세계가 하나이므로).

> 이 선택의 값: 집계가 정말 필요한지는 **시험 결과로** 판단할 수 있다. 지금 만들면 답을 정해 놓고 묻는 꼴이 된다.

## 1. 2-4의 다섯 물음

| 물음 | 답 | 지금과 |
|---|---|---|
| **생산한 물건을 어디 두나** | **밭 안**(`담을수`까지). 창고 건물 없음 | **그대로**(#745) |
| **출발 때 어느 재고가 변하나** | 밭 재고 **−1**, 그 순간 '운반 중'이 하나 생긴다(밭·가게·양·남은틱) | **그대로** |
| **도착 때** | 가게 재고 **+1**, 운반 중 하나가 사라진다 | **그대로** |
| **운반 중 끊기면 기다리나 돌아가나** | **출발한 밭으로 돌아간다**(안 잃어버린다). 길이 다시 이어지면 저절로 다시 나선다 | **그대로**(#745) |
| **생산 시설을 없애면 남은 재고는** | 아래 **1-가** — **고쳐야 한다** | ✗ 바꿀 곳 |
| **저장·복원 때 운반 중 물건** | 밭·가게 재고 · 운반 중(출발·목적·남은틱) · 세대의 '오늘 받았나'를 저장본 `flow` 칸에 | **그대로**(#750에서 확인) |

### 1-가. 지금은 물건이 **설명 없이 사라진다** (통과 못 할 자리)

지금 규칙: **밭을 치우면** 그 밭에서 출발해 길 위에 있던 물건이 **사라진다**(돌아갈 곳이 없으므로). 정본 2-4는 *"물건이 설명 없이 생기거나 사라지는 구현은 통과시키지 않는다"*고 못박았다.

**고칠 안 (제안)**

1. **길에 나선 것은 목적지까지 간다.** 밭이 없어져도 운반 중인 물건은 **가게에 도착한다** — 이미 사람이 지고 길에 있기 때문이다(연기와도 맞는다). 
2. **밭 안에 쌓여 있던 것**은 밭과 함께 사라진다 — 다만 **치울 때 한마디**: `🌾 밭을 치우면 쌓여 있던 3개도 없어져요`(되돌리기 ↩ 로 복구되면 재고도 함께 돌아온다).

→ 이러면 '사라짐'이 **아이가 고른 행동의 결과**로만 일어나고, 화면이 그것을 말한다.

## 2. 시험 세계 수치 (고정 · 정상 상태에서 공급이 끊기지 않게)

| 값 | 정할 값 | 까닭 |
|---|---|---|
| 상품 | **한 종류**(곡식) | 정본 |
| 마을 A | **밭 2** | 하루 생산 = 2 × (1800 ÷ 600) = **6개** |
| 마을 B | **가게 1 · 집 4** | 하루 사용 = 4세대 × 1 = **4개** → 여유 2 |
| 밭 `간격틱` · `양` · `담을수` | 600 · 1 · 5 | 그대로 |
| 가게 `담을수` | 8 | 그대로 |
| `세대몫` · `쓰는시각` | 1 · 낮 12시 | 그대로 |
| **`칸당틱`** | **13** | 사람 걸음과 같은 값(#754에서 재서 정함) |
| 두 동네 사이 거리 | **약 30칸** | 30 × 13 = 390틱 ≈ **시뮬 39분** — 아이가 '가는 중'을 볼 만큼 길고, 기다리다 지치지 않을 만큼 짧다 |
| `운반상한` | 4 | 그대로 |

**정상 상태 확인**: 하루 생산 6 ≥ 사용 4. 가게 `담을수` 8이라 이틀치까지 쌓인다. 끊기면 밭에 5까지 쌓이고 그다음 `full`.

## 3. 화면 셋 (버튼 전환 · 애니메이션 없음)

세 화면은 **같은 세계**를 다른 자리에서 볼 뿐이다.

| 화면 | 카메라 | 함께 보이는 것 |
|---|---|---|
| **고장**(기본) | 두 동네가 다 들어오는 높이 | 두 동네 요약(밭 n · 재고 n / 가게 재고 n · 오늘 받은 집 n) · **연결 상태**(이어짐 / 끊김) · **운반 중 n개** |
| **마을 A** | A 위 | 밭마다 상태와 쌓인 양(이미 `[MAC-FLOWSHAPE]` 가 모습으로 보인다) · [생산 멈춤/재개](시험용) |
| **마을 B** | B 위 | 가게 재고 · 오늘 받은 집 / 못 받은 집 · 가게를 누르면 **까닭**(이미 있는 네 줄) · [공급 경로 보기] → 고장 화면으로 가서 그 연결을 강조 |

- 전환은 **버튼 세 개**. 화면을 바꿔도 세계는 계속 돈다(정본 요구).
- '작은 모형으로 묶기'는 **멀리서 보기**(이미 있는 지도 모드 문턱)로 충분한지 먼저 본다. 모자라면 그때 판단한다.

## 4. 원인 셋 — **이미 있는 것으로 충족된다**

| 정본이 요구한 상태 | 지금 있는 것 | 반드시 보일 것 |
|---|---|---|
| 공급원 없음 | `flowWhyEmpty` → **"이 가게에 오는 밭이 없어요"** | 마을 A 화면으로 보내 밭을 놓게 |
| 연결 단절 | 밭 `cut` + **"밭에 쌓여 있는데 길이 끊겼어요"** + 밭 모서리에 **자루 산더미** | 고장 화면에서 **끊긴 연결 강조** + 출발지 재고 |
| 운송 중 | `moving` + **"곧 와요 — 오는 중이에요"** | 고장 화면에 **운반 중 n개** |

→ **새 판정을 만들지 않는다.** 고장 화면의 '강조'와 '요약 숫자'만 더하면 된다.

## 5. 진입 경로와 저장 (본편과 분리)

- **판 파일** `village/stages/proto-flow.json` · 주소 `?stage=proto-flow`.
- 저장 키 `rpg.village.<sid>.proto-flow` — **본편 저장본과 완전히 분리**(판 구조가 이미 그렇다). 원격 동기도 꺼진다.
- 두 동네는 **시작 저장본**(`시작` 칸)으로 미리 배치한다 — 아이가 마을을 만들지 않는다(정본).
- 본편 규칙·기존 저장본은 **한 줄도 안 건드린다**.

## 6. 완료 시험 넷을 어떻게 볼 것인가 (정본 2-5)

| | 할 일 | 볼 것 |
|---|---|---|
| **A 정상 공급** | 잇는다 → 하루 돌린다 | 생산 → 출발 → 도착 → 사용이 숫자로 이어지고, 화면을 오가도 그대로 |
| **B 연결 단절** | 사이 길 한 칸을 치운다 | 운반 중이던 것이 **밭으로 돌아오고** · 까닭이 '연결 단절' · 다시 이으면 **390틱 뒤** 회복 |
| **C 공급원 제거** | 밭을 치운다 | 길에 나선 것은 **가게까지 가고**(1-가) · 밭에 쌓인 것은 **한마디와 함께** 없어지고 · 까닭이 **'오는 밭이 없어요'**(B와 다른 말) |
| **D 저장·복원** | 운반 중에 저장 → 다시 열기 | 재고·운반 중·시간이 그대로 |

## 7. 이번에 만들 것 / 안 만들 것

**만든다**: 판 파일 하나(시작 저장본 포함) · 화면 전환 버튼 셋 · 고장 화면의 요약과 연결 강조 · 1-가의 고침(운반 중은 목적지까지 · 밭 치울 때 한마디).

**안 만든다**: 마을 단위 집계 · 마을 재고 · 줌 애니메이션 · 돈·가격·양방향 · 여러 상품 · 아이가 마을을 새로 만드는 기능.

## 8. 아직 못 정한 것 (구현하며 정할 것)

- '작은 모형으로 묶기'를 **멀리서 보기로 충분한지** — 모자라면 무엇을 더할지(정본은 완성형 줌을 금지했다).
- 고장 화면의 **연결 강조**를 무엇으로 할지(기존 ✨ 반짝임? 길 색?) — 새 장치를 만들지 않는 쪽으로.
- 두 동네를 **한 구역에 넣을지 두 구역에 걸칠지**(구역은 32×32다 · 30칸 거리면 두 구역이 필요할 수 있다).
