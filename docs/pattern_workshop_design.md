## 2. 시중 프로그램이 못 하는 것
1. **헷갈림을 이름으로 잡는다** — 틀린 답이 무엇이었는지로 '좌우 · 위아래 뒤집기 헷갈림', '돌리는 방향 헷갈림', '뒤집기 · 돌리기 헷갈림', '돌린 각도 헷갈림'을 센다 → 선생님 지도.
2. **답이 여럿인 것을 정답으로** — 위아래가 같은 도장은 '그대로'와 '아래쪽으로 뒤집기'가 같은 그림. 움직임 이름이 아니라 결과 그림으로 채점하고, "다른 답도 맞아요 — 왜 같을까요?"를 보여 준다(교육과정 고려 사항 그대로).
3. **움직임을 눈으로** — 고른 움직임을 도장이 실제로 해 보인다(뒤집기 = 종이를 뒤집듯 3D로 · 돌리기 = 빙그르). 틀린 답도 "그렇게 움직이면 이렇게 돼요"를 해 보인다.
4. **우리 반 · 우리 세계**(다음 판): 나의 무늬 → 우리 반 무늬 전시 → **친구 무늬의 규칙 맞히기**(친구 작품이 탐정 문제가 됨) · 내 방 벽지/바닥(꾸미기 — RPG 본 데이터라 사용자 승인 뒤).

## 3. 낱말 · 움직임 (아이 말)
| 키 | 버튼 이름 | 같은 것(다른 말) |
|---|---|---|
| id | 그대로(밀기) | 시계 방향 360° |
| fh | 오른쪽으로 뒤집기 | 왼쪽으로 뒤집기 |
| fv | 아래쪽으로 뒤집기 | 위쪽으로 뒤집기 |
| r90 | 시계 방향 90° | 시계 반대 방향 270° |
| r180 | 180° 돌리기 | 시계 방향 · 반대 방향 180° |
| r270 | 시계 반대 방향 90° | 시계 방향 270° |
- 도장 = 정사각형 칸 그림(4×4 ~ 6×6). 칸 그림이라 움직임 결과가 정확하고(시험이 그림끼리 견줌), 아이가 직접 그리기도 쉽다.
- 무늬 = 규칙 칸(1칸 · 가로 2칸 · 세로 2칸 · 2×2)에 움직임을 정하고, 규칙 칸을 **밀어** 판을 채운다.

## 4. 장 · 판 (정본 = `pattern/js/stages.js`)
| 장 | 판 | 판의 뼈 |
|---|---|---|
| 1 뒤집기 | 6 | 고르기(오른쪽으로 · 아래쪽으로 뒤집으면?) · 탐정(어떻게 움직였나) · 누구 말이 맞을까(왼쪽으로 = 오른쪽으로) · 위아래가 같은 도장(그대로 = 아래쪽으로 뒤집기) |
| 2 돌리기 | 6 | 시계 90° · 반대 90° · **ㄱ을 180° 돌리면 ㄴ** · 탐정 · 반대 90° = 시계 270° · 180° 돌리기 ≠ 뒤집기(깃대를 봐요) |
| 3 움직임 탐정 | 6 | 섞어서 · 답이 여럿(반쪽 색칠 정사각형: 시계 90° = 아래쪽으로 뒤집기) · 친구 설명 검토 |
| 4 무늬 만들기 | 6 | 밀기만 · 오른쪽 뒤집기 번갈아 · 아래쪽 뒤집기 번갈아 · 줄마다 뒤집기 · **바람개비**(돌리기 2×2) · **거울 무늬**(뒤집기 2×2 = 대칭) |
| 5 무늬 고치기 | 4 | 한 칸이 틀린 무늬 — 틀린 칸을 찾고 맞는 움직임으로 |
| 6 나의 무늬 | (다음 판) | 도장 그리기 + 규칙 칸 + 전시 · 친구 무늬 규칙 맞히기 |
- 별: 첫 번에 ★★★ · 두 번째 ★★ · 그 뒤 ★. 순위 · 골드 없음. 장 안에서 앞 판을 풀어야 다음 판(선생님 `?teacher=1` 은 다 열림).

## 5. 저장 (`classRPG_pattern` · 기초 코딩과 같은 꼴)
- `progress/<sid>/<판>` = { st, n(몇 번 만에), t } · `stats/<sid>/<판>` = { tries, ok, axis, dir, angle, fliprot, still, find } (서버 increment) · `names/<sid>`.
- 손님(sid 없음)은 이 기기 localStorage. RPG 본 데이터는 안 건드림(선생님 비밀번호 확인 한 번 읽기만).

## 6. 선생님 헷갈림 지도(`#/t` · 관리자 비밀번호)
- 아이 × 판 표 + 아이마다 헷갈림 셈(좌우·위아래 / 돌리는 방향 / 뒤집기·돌리기 / 각도) · 반 전체에서 가장 많은 헷갈림.
