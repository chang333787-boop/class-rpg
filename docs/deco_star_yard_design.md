## 1. 모습 해석기 — `_yardLook(sp)` · `YARD_LOOKS`
공간(1 · 2 · 3)마다 표 한 줄을 돌려준다. 그리는 코드는 `_seaNow()` · `_decoPhase()` · 하드코딩 색 대신 이 줄만 읽는다.

| 칸 | 뜻 | base(=지금 · 여름 낮) | winter(예) | star |
|---|---|---|---|---|
| `season` | 나무 · 꽃 · 우리 · 풀 조각 | summer | winter | **없음**(결정 3 · 여름 그림 그대로) |
| `phase` | 때(막 · 불빛 · 동물 잠) | 실제 시각 | 실제 시각 | **night 고정** |
| `ground` | 잔디 무리 칸 바탕 · 무늬 kind | 무늬 grass | `#eef3f8` + snow | `#1b2a72` 계열 + star(`star_patch_nebula/sparkle`) |
| `groundFrag` | `fringe_grass_*` · `ground_tuft_*` 조각 | '' | winter | star |
| `waterFrag` | `tile_water_a/b` 조각 | '' | winter | star |
| `shadow` | 밑동 그림자 색 | `rgba(30,52,14,.30)` | (같음) | `rgba(10,12,40,.40)` |
| `houseGround` | 집 밑 땅 | grass | (계절 따라) | star 땅 |
| `farm` | 밭 흙 색 | 지금 값 | 지금 값 | 지금 값(달 흙은 사용자 결정) |
| `sky` | 판 밖 | 전체화면 틀 남색 `#0E1621` | 같음 | `ui/sky_stars.svg` CSS 배경 |
| `edge` | 섬 가장자리 | 없음 | 없음 | `island_edge_*` |
| `film` | 색 막 세기 | 때 따라(밤 .48) | 때 따라 | P0 시안으로 고름(.20/.30/.45) |
| `events` | 계절 행사 | 켬 | 켬 | **끔**(결정 3) |
| `guests` | 손님에게 넘기는 계절 · 때 | 계절 · 시각 | 계절 · 시각 | 계절 없음 · 밤 |

- **우선순위**: ① 개발 스위치 `?look=`(놀이판 주소일 때만 — 운영 경로에서 읽지 않는다 · PR 마다 grep 으로 확인) ② (P6a 를 한다면) 별빛 축제 주간 날짜 창 ③ (P6b) 아이가 고른 `yardLook.sN` ④ 기기 달의 계절.
- **LOOK-0 에서 정한 것**: 해석기는 둘 — `_yardLook(sp)`(계절 줄 · 고정 객체라 칸마다 불러도 새로 안 만듦) · `_yardPhase(sp)`(줄에 `phase` 가 박혀 있으면 그것 · 없으면 실제 시각 · 단추). 별빛 줄은 `phase: 'night'` 으로 밤 고정. 때를 바꾸는 단추(`decoPhaseCycle`)만 `_decoPhase()` 를 직접 읽는다(입력이라서).
- **P3 에서 정한 것**(보스 잠정 시안 A — 은하수 띠 + 밤 막 .30 · 막은 P5): 잔디 무리 칸 = `star_ground`(9칸 주기 무늬) 위에 `star_band`(판 80×44칸 한 장)를 그 칸 자리째 붙인다 — 되풀이하면 줄무늬라 한 장이고, 한 장을 화면 해상도로 구우면 40MB 가 넘어 **8×8칸 조각**으로 구워 둔다(칸당 기기 px 64 까지 · 픽셀 합 6M 에서 비움). 섬 = `island_rim` 칸마다 + `island_under` 판 폭 한 장(1600×120 — 디자인 문서) · 판 밖 `sky_stars` 400×400 은 P5. 켜는 길은 아직 놀이판 개발 스위치 `?look=star` 뿐(`window.__PLAY` + 가짜 프로젝트 `play-deco-none`).
- **LOOK-0(첫 코드 PR)**: 표를 만들고 하드코딩 다섯 곳(`_floorBaseName` 잔디 이름 · 얼룩 무늬 · 밑동 그림자 · 집 밑 잔디 · 밭 모래 색)과 줄의 `_seaNow()` · `_decoPhase()` 호출을 표 읽기로 바꾼다. **관문: 기본 마당 픽셀 지문 · 계절 넷 지문 · deco-perf 수치가 바로 앞 커밋과 같다(보이는 변화 0).**

## 3. 그리는 순서(별빛 공간)
판 밖 하늘(CSS · 캔버스 비용 0) → 섬 가장자리(확대 단계 `_bmpStep` 키로 따로 구운 띠 · 틀마다 drawImage 몇 번 — 비용 0 이 아님) → 바닥(굽기) → 땅 무늬 → 장식 · 밭 → 밤 막(편집 중 · 카드를 든 동안 절반) → 창 불빛 → light_pool → glow('lighter' · 보이는 광원만 · 상한 24) → 집 이름표 · '들어가기'(막 위에 다시) → DOM: 동물 층(class 로 `brightness(.8) saturate(.85)`) · 반짝임(P7).
- 줄의 `_decoNightDraw` 가 막 · 불빛 · 창을 이미 이 순서로 그린다 — 별빛은 `phase: night` 로 그것을 부른다.

## 4. 친구 구경 · 다른 그리는 곳
- **친구 구경(`_renderFriendCanvas`)**: 친구 문서의 공간 1 모습으로 그린다. 켤 때 친구 값으로 하늘 배경을 바꾸고 `closeFriendFullscreen` 에서 되돌린다. '친구 모습 ≠ 내 모습' 경우를 시험에 넣는다.
  - 진행 중인 친구 구경 개편(`docs/deco_friend_visit_20260924.md` ① — 꾸민 곳 상자 + 둘레 한 칸으로 잘라 27px)과 겹친다: 그렇게 자르면 **섬 가장자리 · 판 밖 하늘이 거의 안 보인다.** 별빛 공간이면 자르는 상자에 섬 가장자리 한 칸을 더 넣는다(결정 ⑤). 이름표(`ui_wood_sign`)는 막 위에 다시 그린다.
- **그 밖에 마당을 그리는 곳**: '내 기록'의 작은 판(house-topview · DY_NORMAL) · 사진(`decoPhoto` · `_decoPhotoFrame`) · 선물 상자 사진 조각(`_lifePhotoPaint` — `_dCv` 를 복사해 CSS 하늘 · DOM 동물이 빠진다 → 별빛이면 하늘색 바탕을 먼저 깔고 복사) · 방문 모달 미리보기(`renderDecoCanvas` — 없는 요소를 겨냥하는 죽은 코드로 보인다 · 확인 뒤 지울 후보).

## 5. 저장 (P6b 만)
- 모양: `students/<id>/yardLook = { s1?: 'star', s2?: 'star', s3?: 'star' }`(40B 이하 · 글자 키). 없으면 지금 마당과 같고 **켜지 않은 아이의 문서는 그대로.**
- 쓰기: 고를 때만 **잎 update**(`yardLook/sN = 'star'` · 끄면 null) — 통째 set 을 늘리지 않는다(#288). 쓰기 함수 하나로(`_lifeSend` 와 같은 모양).
- **교사 통째 저장이 yardLook 을 되돌리는 길(#288)**: 교사가 보상을 승인하며 옛 사본으로 학생 문서를 통째 set 하면 켠 모습이 조용히 기본으로 돌아간다. `scripts/unit/deco-life-sync-sim.mjs` 가 하트에서 같은 되돌림을 잰다(실제 간격 0.75%) → yardLook 한 판을 더해 수치를 PR 에 적는다. 되돌아가도 아이가 다시 고르면 되고, 잃는 것은 모습뿐(골드 · 장식 0).
- **Firebase rules**: 저장소에 rules 파일이 없다. `decoLife`(선택 필드 · #1001)가 운영에서 통과하고 있으면 모르는 필드를 거부하지 않는 것 — P6b 전에 보스가 운영 rules 를 읽어 확인한다(학생 데이터는 보지 않는다).
- 교사 '수치 초기화'(admin.js 두 곳)에 `s.yardLook = {}` 한 줄 — decoLife 선례대로 이 담당이 넣는다(보스 결정 ③ 선례).
- ↩ 되돌리기: 모습 바꾸기는 ↩ 20단계에 **넣지 않는다**(장식 조작이 아니다 · 다시 고르면 된다).

## 6. 끄는 스위치 · 롤백
- **학생 화면에는 강제 새로고침 장치가 없다**(student.js · student.html · gamedata.js 에 `location.reload` · 버전 검사 0건 — admin.js · kiosk.js 에만 있다). 열린 탭은 새로고침할 때까지 옛 JS · 옛 모습 그대로다.
- 그래서 끄는 스위치는 **settings 노드**로 둔다: 교사 기기가 쓰고 학생 기기가 실시간으로 받는다(gamedata.js `liveHandler` 는 저장 중에도 settings 변경을 반영 · `shopOverrides` 선례). 예 `settings.decoLookOff: true` → 해석기는 `base`/계절만 돌려준다. 배포 없이 켜고 끈다.
- 거둔 뒤 남은 `yardLook` 값: 모르는 값 · 꺼진 기능이면 **기본으로 그리고 지우지 않는다**(다시 켜면 돌아온다).
- **새 장식 id(P9) 전**: 옛 JS 탭은 새 id 를 모른다(`GAME_DATA` 에 없음) → 친구 구경에서 빈칸으로 보이고, 그 칸이 비어 보여 옛 JS 에서 겹쳐 놓일 수 있다. 막는 법(결정 ⑦): settings 에 '최소 판'을 두고 낮으면 "새로고침해 주세요" 한 줄 — 학생 화면 첫 새로고침 장치.
