# 학습 플랫폼 설계 연구 (2026-07-31)

> 목적: RPG 안에 만들 학습 기능이 "공부할 만한 플랫폼"으로서 값어치가 있는지 판단하고,
> 있다면 무엇을 만들고 무엇을 만들지 말지 정한다.
> 방법: 실사용 DB 실측(퀴즈 162세션·862문항) + 4갈래 문헌·경쟁도구 조사.

## 0. 한 줄 결론

**어휘 반복 학습과 대규모 문항 은행은 이미 진 싸움이다.**
우리 앱이 이길 수 있는 건 **"우리 반 문항을 1분 안에 넣고, 30초 안에 누구를 도울지 보는 것"** 하나다.

| 활동 | 최근 상태 |

살아남은 둘은 ①매일 새 내용이 자동 공급되고 ②홈 최상단에 뜨고 ③보상이 있다.
죽은 다섯은 **셋 다 없다.** 방학 탓이 아니다(같은 기간 퀘스트는 최고치).

### 1-2. 판별하지 못한 것 (정직한 한계)

간격별 정답률: 1일 70% · 2~3일 81% · 4~7일 78% · 8~30일 79% · **31일+ 81%**.
선택 편향을 의심해 구간별 단어 난이도를 재봤으나 전 구간 0.25~0.26으로 균일 → 편향 아님.
**그런데도 망각곡선이 안 보인다.** 4지선다 추측률 25%가 신호를 가리거나, 24단어를
4개월 반복해 과잉학습된 것으로 추정. **현 형식으로는 간격 효과를 측정할 수 없다.**

### 1-3. 조사 중 정정한 내 오류 2건

- ❌ "오답 보기가 24단어 세트 안에서 고정된다" → **틀림.** 전체 500단어에서 뽑는다
  (200회 시뮬레이션 결과 보기 조합 186~200가지). 호출부를 안 보고 함수만 보고 판단한 잘못.
- ❌ "가장 많이 틀린 단어 = 어려운 단어" → **틀림.** 노출 횟수 미보정이었다.
  출제 횟수로 나눈 오답률로 재계산함(위 표는 재계산 값).

## 2. 문헌이 말하는 것

### 2-1. 의미가 가까운 오답은 초급에게 해롭다 — 우리 데이터와 일치

- **Erten & Tekin (2008), System** — **초등 4학년 60명 직접 연구.** 의미 무관련 단어 묶음이
  성적도 좋고 학습 시간도 짧았다. 저자들이 "교과서 관행과 반대"라고 명시.
  https://www.sciencedirect.com/science/article/abs/pii/S0346251X08000420
- **Nakata & Suzuki (SSLA)** — 총 정답률은 안 무너지는데 **범주 안에서 서로 맞바꿔 틀리는
  오류(within-set interference)가 집중**된다. → 우리 실측(school 34% vs clothes 13%)이 이 패턴.
  https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/F58BA8D70385603B9C42E408BFCB8A10
- **Nation (2000), TESOL Journal** — 관련 단어를 동시에 배우면 더 어려워진다.
  https://onlinelibrary.wiley.com/doi/10.1002/j.1949-3533.2000.tb00239.x

**단, 반대 증거도 탄탄하다.** Little & Bjork (2012, 2015)는 경쟁적 오답이 인출을 촉진한다고
보고했다(Psychological Science). 폐기가 아니라 **순서 문제**로 푼다 —
**초기엔 의미 거리를 벌리고, 숙달 후 의도적으로 붙여 변별 훈련.**

조절변인 3가지: **학습 단계**(형태-의미 연결 형성 중이면 해로움) · **숙련도**(초급일수록 해로움) ·
**맥락**(스토리북에 넣으면 간섭이 사라짐 — McDonald & Reynolds 2023).
→ **초등4 + 초급 + 맥락 없는 4지선다 = 문헌이 지목하는 최악의 조합.**

### 2-2. 간격 반복 — Leitner면 충분하다

SM-2·FSRS는 **학습자 자기평가(q 0~5 / G 1~4)를 필수 입력**으로 요구한다. 우리는 정/오 binary뿐이라
축약하면 사실상 Leitner와 같아진다. FSRS는 21개 파라미터를 수천 리뷰로 최적화해야 이점이 나오는데
한 학급 데이터로는 불가능. HLR은 Duolingo 규모 인프라 전제.
→ **Leitner 박스 + 간격표.** 설명 가능성("3번 상자")도 교실에서 기능적 가치가 있다.

핵심 근거:
- **Sobel, Cepeda & Kapler (2011)** — 5학년 39명, 1주 간격 복습이 즉시 복습보다 5주 후 우세(**d=0.5**).
  https://www.yorku.ca/ncepeda/publications/SCK2011.pdf
- **Cepeda et al. (2008)** — 최적 간격 ≈ 목표 파지 기간의 **10~20%**. 학기말(120일) 목표면 **12~24일**.
  현재 앱은 "최근 3일 내 출제 0.5배" 가중치로 실질 최대 간격이 3일 근처. **자릿수가 다르다.**
  https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf
- **Belardi et al. (2021)** — 웹앱 어휘 학습 직접 검증. 분산(20분×4 > 80분×1) **+24.7%p**,
  **오답 시 정답 표시 +5.2%p**. https://www.frontiersin.org/articles/10.3389/fpsyg.2021.757262/full

**방학·결석 대응**: 달력 날짜 대신 **수업일 인덱스**(앱을 쓴 날에만 +1)로 스케줄링하면
6주 방학 후에도 밀린 카드가 폭발하지 않는다. + **세션 하드 캡**(due가 200개여도 12문항만),
**"밀린 개수"를 학생 화면에 절대 표시하지 않기**. Anki 이탈 1위 원인이 review debt다.

**81%는 아마 문제가 아니다**: Wilson et al. (2019) "85% 규칙" — 최적 훈련 정확도 ≈ 85%.
Anki 기본 목표 파지율도 90%. https://www.nature.com/articles/s41467-019-12552-4

### 2-3. 교사 대시보드 — 만들어도 안 본다

- **Wise et al.** 실측: 교사 주당 로그인 **0.79회**, 개별 학생 페이지 **주당 0.6분**,
  연간 총 7시간, **43%는 연간 1시간 이하**. https://pmc.ncbi.nlm.nih.gov/articles/PMC4292877/
- **Kaliisa et al. (2023)** 체계적 검토(1,968편 스크리닝): 대부분의 대시보드는 **인식(awareness)에서
  멈추고 실행 가능한 통찰을 못 준다.** https://educationaltechnologyjournal.springeropen.com/articles/10.1186/s41239-023-00394-6
- **PNAS 메가스터디** (교사 140,461명 / 학생 299만 명): 15개 개입 중 최고 효과는
  **"매주 대시보드 로그인" 넛지**(+5.06%), 그리고 **"우리 반 실제 숫자"를 언급한 알림이
  일반 알림보다 +2.26%** — 객관 코딩 속성 중 유일하게 유의. https://www.pnas.org/doi/10.1073/pnas.2418616122
- **Black & Wiliam**: 총괄 점수를 피하고, **학생 간 비교를 피하라.**
  → 현재 앱의 "학생별 정답률 목록"은 정확히 피하라고 한 형태.

**설계 제약**: 교사가 쓰는 시간 = **주당 1~3분**. 스크롤·탭·드릴다운이 필요하면 그 기능은 없는 것과 같다.

### 2-4. 경쟁 도구 — 이미 진 싸움을 식별하기

단 국책 플랫폼도 혹평받았다 — 교사 인터뷰: *"AI가 맞다/틀리다 말고 다른 피드백을 못해주는
거라면 AI란 이름을 붙이면 안 된다"* (오마이뉴스). 적응형의 실체는 "진단평가 오답 + ★2개 이하"
규칙 기반이었다.

## 3. 설계 결론

### 🚫 만들지 말 것

1. **간격 반복 확률 모델** — Quizlet이 AUROC 0.815로 이미 함. 25명 데이터로 원리적 불가
2. **어휘 4단계 파이프라인 재구현** — 클래스카드의 열화판이 됨
3. **대규모 교과 문항 은행** — 칸 4,700포인트·똑똑수학탐험대 무료와 경쟁 불가
4. **자체 "AI 맞춤" 브랜딩** — 국책 플랫폼도 이 이름값으로 신뢰를 잃었다
5. **실시간 멀티 퀴즈 배틀** — 클래스카드 퀴즈배틀·Quizlet Live가 무료
6. **학생 정답률 순위표** — 낙인·사회적 불안. Black & Wiliam이 명시적으로 금지
7. **총 학습 시간 / 총 푼 문제 수 표시** — 허영 지표. 어떤 결정도 유발 안 함

### ✅ 만들 것

1. **교사가 1분 안에 문항을 넣는 경로** — 3교시에 틀린 걸 4교시 퀘스트로.
   상용 도구는 전부 "별도 앱 + 별도 세트"라 구조적으로 불가능
2. **학급 맥락 문항** — 우리 반 이름·사건·가지 그림책 등장인물이 소재로.
   전국 공통 문항인 상용 플랫폼이 원리적으로 못 하는 것 = **진짜 해자**
3. **RPG 통합** — 학습 결과가 성장·역할·학급 이벤트로. 앱 안에 갇힌 게임화와 다름
4. **교사 "오늘 화면" 하나** — 30초 판단. 딱 3가지:
   ①아직 안 한 아이 ②**반의 절반 이상이 틀린 문항** ③연속 오답으로 막힌 아이
5. **혼동행렬 기록** — ⚠️ **현재 불가능.** `wrongDetails`에 문항 유형만 있고
   **선택한 오답이 없다.** `afternoon`을 틀린 건 알지만 `evening`을 골랐는지 모른다.
   **이 한 필드가 위 진단 전부의 전제**
6. **숙달 4단계 (칸 축소 차용)** — 안 함 / 해봄 / 익숙 / 완료.
   **"연습만으로는 최고 단계에 못 간다, 섞인 문제 시험을 통과해야 한다"** 규칙 포함
7. **Leitner 박스 + 수업일 인덱스** — 간격표 [0,1,2,4,8,16] 수업일.
   오답 시 전면 리셋 대신 −1 강등(4지선다 추측 25% 노이즈 대응)
8. **오답 보기 단계별 정책** — 초기엔 같은 범주 **0~1개 하드 캡**, 숙달 후 변별 훈련으로 상향
9. **오답 시 정답 즉시 표시** — +5.2%p, 구현 비용 0 (현재도 일부 있음)
10. **"찍어서 맞은 문제" 분류** — 풀이 시간만 기록하면 구현 가능(웅진 방식)

## 4. 열린 질문 (데이터로 판별해야 함)

1. **81% 정체의 원인** — (a) 간격 부족 (b) 4지선다 재인 천장 (c) 애초에 최적 구간.
   현재 데이터로 판별 불가. `results` 맵 + 선택한 오답을 2~4주 수집하면 판별됨
2. **보상 방침** — 보상 없는 활동이 예외 없이 전부 죽었다(§1-1). 방침 유지 시 학습게임도
   같은 길. **사용자 결정 필요** (이 문서는 보상을 다루지 않음 — 사용자 요청)
3. **문항 은행 규모** — 칸·똑똑수학탐험대와 경쟁하지 않는다면 89문항을 몇 개까지 키울 것인가.
   "학급 맥락 문항"만 남기고 일반 문항은 외부로 넘기는 선택지도 있음

## 5. 확신도

| 주장 | 확신도 |
|---|---|
| 보상 없는 활동이 전부 죽었다 (실측) | **높음** — 다만 학생 7명 표본 |
| 반복 학습 효과 65%→81% (실측) | **높음** |
| 의미 근접 오답이 초급에게 해롭다 | **높음** — 초등4 직접 연구 포함, 단 반대 증거도 존재 |
| 간격은 주 단위여야 한다 | **높음** — Cepeda, Sobel |
| 교사는 대시보드를 거의 안 본다 | **높음** — 단 미국 학구 사례, 한국 초등 미검증 |
| Leitner가 이 앱에 적합 | **중상** — 입력 신호 부재가 근거, 직접 비교 실험은 없음 |
