# 🚏 버스 정류장 — 제안서 한 장 (2026-09-21 · 맥북 마을 프로그램 담당 · **구현 전 · 보스가 고른 뒤**)

> 창조자의 눈 6회 🟢: "정류장에서 길로 N칸 안의 집은, 그 하나뿐인 건물 곁에도 정류장이 있으면 '가깝다'로 친다." 첫 도시 씨앗.
> 까닭(6회 🔴2): 516명 마을의 3층 27채가 **전부 도서관·학교 20칸 안**. 하나뿐인 건물은 멀리 사는 집에 영영 '멀어요'다.
> 내 몫 = 규칙·해금·목표. 버스가 다니는 모습(연기)·정류장 모양(디자인)은 따로.

## 한 줄
**정류장은 '먼 곳을 가깝게 만드는 길가 물건'이다.** 집이 정류장 A 에서 걸어서 **8칸** 안이고, 특별 건물(학교·박물관·기차역)이 정류장 B 에서 **6칸** 안이며, **A 와 B 가 길로 이어져 있으면**(거리 무관) 그 집은 그 건물을 '가깝다'로 친다. 저장 필드 0(물건 한 종류 — palette 에 붙을 뿐).

## ⓐ 규칙 (판정)
| | 제안 | 까닭 |
|---|---|---|
| 걸어서 정류장까지 N | **8칸**(길 따라) | 필요 판정(14칸)보다 짧아야 '정류장 곁에 산다'가 뜻을 가진다 |
| 정류장에서 건물까지 M | **6칸** | 건물 곁에 붙여 놓게(아이의 한 수가 분명하게) |
| 두 정류장 사이 | **길로 이어지기만 하면**(거리 무관) | 도시의 '버스' 느낌. 이어짐은 길 덩어리(연결 요소)로 센다 |
| 무엇이 가까워지나 | **특별 건물만** — 학교(배움·놀이) · 박물관(놀이) · 기차역 | 우물·가게·도서관(이제 여럿 — #615)까지 되면 '동네마다 짓기'가 사라진다. 버스는 **하나뿐인 것**에 가는 길 |
| 몇 개까지 | 정류장 cap **8** | 판 도배 방지 · 연결 계산 비용 |

- `computeSat` 감싸기: 원래 셈 뒤, 그 집의 길 BFS(이미 돈다) 안에 8칸 안 정류장이 있으면 → 그 정류장과 **같은 길 덩어리의 다른 정류장들** 곁(6칸) 특별 건물의 `need`/`need2` 를 `met` 에 더한다. 붐빔(#670)의 교통량은 정류장까지만 센다(버스 탄 사람은 길을 안 쓴다 — 붐빔을 덜어 주는 효과도 생긴다).
- 정류장 목록·'정류장 → 곁 특별 건물'·길 덩어리 번호는 **놓기·치우기 때만** 다시 센다(틱 비용 0 · 광장 캐시 #658 과 같은 꼴). 판정 추가 비용: 집마다 BFS 안 정류장 확인 한 번.

## ⓒ 저장 · v3 '길가 물건' 층과의 관계
- **v2 그대로**: 새 종류 `busstop`(1×1) 하나 — palette 에 이름이 붙고 구역 문자열에 들어간다. SAVE_V 안 올림. 옛 판은 모르는 종류를 못 그리지만(`K` 에 없음) 저장본은 망가지지 않는다 — **운영 마을엔 해금 뒤에만 생긴다**.
- **v3 전**: 길 **곁 빈 칸**에 놓는다(`needRoad` — 우체통·가로등처럼). 한 칸을 먹는다.
- **v3 뒤**(디자인 전수표의 `place:'roadside'`): **길 칸 위 가장자리**에 선다 — 풀밭 칸을 안 먹고, 길 방향으로 돌아선다. 종류 id 가 같으니 v3 이행 때 칸만 옮기면 된다(길 곁 칸 → 곁 길 칸의 가장자리). 판정(길 BFS 거리)은 둘 다 같다.
- `sync.js`: 종류만 늘 뿐이라 손댈 것 없음.

## ⓔ 반대 안
- **A. 거리 늘리기**(버스 없이 특별 건물의 범위를 20→40칸): 한 줄로 끝나지만 '아이의 한 수'가 없다(#610 에서 버린 ②와 같은 까닭).
- **B. 특별 건물을 여럿**(학교도 도서관처럼): 도시 느낌이 안 난다 · 박물관·역은 하나라서 뜻이 있다.
- **C. 정류장 = 모든 필요**: 가장 강력하지만 동네 시설이 필요 없어진다 — 마을 게임의 핵심(필요 보고 놓기)이 무너진다.
