# 음악실 MUSIC-ROOM-1 (2026-10-03)

사용자 요청(10-03): "작곡 프로그램 새로 만들어줘 — 더 의미 있고 다양한 기능, 학습 칸에, 아이들이 자기 곡 저장" →
"리코더: 소리 듣고 틀린 음 잡기는 빼고, 나비야 같은 곡의 악보가 지나가며 연습(게임처럼)" · "키보드로 오투잼처럼".

## 한 곡을 세 곳에서
| 곳 | 하는 일 | 교과와 닿는 곳 |
|---|---|---|
| 작곡 | 칸을 눌러 가락 짓기(음 길이 고르기) · 반주 친구(화음·베이스·장단) · 느낌 바꾸기 · 악보 · 리코더 운지 · 노랫말 · 코치 · 아이디어 친구 | 창작(가락·리듬 만들기, 노랫말 붙이기), 주요 3화음, 5음 음계·평조·계면조, 국악 장단 |
| 리코더 연습 | 음표 발판이 흐르고 몬스터가 박에 맞춰 밟음 · 왼쪽 큰 운지(바뀌는 구멍 노란 테두리) · 빠르기 3단 · 가락/반주 켜고 끄기 · 끝나면 스스로 별 → 리코더 기록장 | 기악(리코더), 자기 평가 |
| 리듬 게임 | 8줄 건반(A S D F / J K L ; = 도~높은 도) 또는 4줄 · 2박 넘는 음은 길게 누르기 · 칠 때 그 음이 울림 · 등급·최고 기록 | 박·리듬·음 높이 감각 |

친구가 음악회에 올린 곡으로도 리듬 게임·리코더 연습을 할 수 있다(내 곡이 친구의 연습곡이 된다).

## 파일 (`music/`, 빌드 없음 · ES 모듈 · import map 으로 캐시 번호)
- `theory.js` 음 이름·음계·박자·음표 길이·주요 3화음 고르기(node 로 시험) · `library.js` 기본 곡 9개 · `song.js` 곡 모양·소리 사건(반주 포함)
- `audio.js` Web Audio 합성(피아노·실로폰·마림바·리코더·가야금 = Karplus-Strong, 베이스·화음, 북·장구 덩/쿵/덕/기/더러러러) · 소리 파일 0개
- `notation.js` 오선 악보 SVG(높은음자리표·박자표·점·붙임줄·이음줄·덧줄·쉼표·계이름·노랫말·화음 이름) — 글리프는 Noto Music 을 필요한 글자만
- `recorder.js` 소프라노 리코더 운지(바로크/저먼) · `coach.js` 코치·아이디어 친구 · `compose.js` / `practice.js` / `rhythm.js` / `teacher.js` / `app.js`

## 저장 (`classRPG_music` — RPG 본 데이터 `classRPG_v3` 는 읽지도 쓰지도 않음)
- `songs/<sid>/<곡id>` 곡 전체 · `songlog/<sid>/<곡id>/<때>` 저장할 때마다 한 줄(지우지 않고 쌓음 → 연구용 '만든 과정')
- `concert/<sid>_<곡id>` 음악회 목록(작은 줄) · 선생님 숨김 `hide`
- `practice/<sid>/<곡키>` 리코더 기록장(횟수·마지막·별) + `log` 쌓기 · `rhythm/<곡키>/<sid>` 최고 기록
- RPG 에서 열면 `?sid=&n=` → 그 이름으로 저장. 그냥 열면 손님(이 기기 localStorage). 선생님 = `music/index.html?teacher=1#/t`(관리자 비밀번호)
- 보상(골드·EXP)과 묶지 않음 — 경제 결정은 사용자 몫

## 사실 확인
- 나비야 계이름: 동요 계이름 모음 두 곳 대조(2·4째 줄 끝 '도미솔솔 미미미'). 원곡 = 독일 민요 Hänschen klein(위키백과)
- 리코더 운지: 바로크 '파' = 엄지·1·2·3·4·6·7, 저먼 '파' = 엄지·1·2·3·4. 높은 미·솔 = 엄지 반 구멍. **저먼식 파#·높은 파는 확인 못 해서 넣지 않음**(그 음이 있는 곡은 저먼식 연습 목록에서 빠짐)
- 장단 구음: 세마치 = 덩 · 덩 | 쿵 · 덕 | 쿵 덕 ·, 굿거리 = 덩 · 기덕 | 쿵 · 더러러러 | 쿵 · 기덕 | 쿵 · 더러러러 — 교과서 정간보와 한 번 더 대조할 것
- 성취기준 번호(2022 개정 음악 창작 영역)는 공개 검색으로 원문을 못 찾음 → 연구 보고서에 쓸 때 원문 대조
- 가사는 넣지 않음(기본 곡은 계이름만). 노랫말은 아이가 직접 씀

## 시험(헤드리스, 운영 DB 막음)
- 소리: 7악기 × 3음 오프라인 렌더 → 자기상관 음높이 ±6센트(측정 눈금 안), 북·장구 8종 소리 남
- 리듬 게임 자동 연주: 나비야 54/54 완벽, 작은 별 48/48(긴 음 6개 끝까지 누르기 포함)
- 악보: 2/4·3/4·4/4·12/8·16분음표·점음표·못갖춘마디 쉼표 그림 확인
- RPG 놀이판: 오늘의 학습 → 음악실이 `?sid=&n=` 달고 열림 · 내 집 '리코더' 칸 → 리코더 기록장
