# 산책 목적지 — 공원에 '머무는 무리'가 생기게 (설계 한 장)

> 2026-09-24 · 주민 연기 담당 · 보스 결정 (가) · **설계만(코드 0) — 보스 승인 뒤 구현**
> 앞선 것: 원본 마을 공원 길(#940) · 지나가다 앉기 시안 ACT-SITBY(로컬 · 보류: 하루 0~2번 · 까닭 모를 흔들림)

## 두 문장

1. **아이가 새로 보는 것** — 공원(긴의자·정자·마을 나무·연못가)을 두면, 오후에 이웃들이 **그리로 걸어가 둘셋씩 모여 앉아 쉬는 모습**이 보인다. 지금은 공원에 사람이 비어 있어 "여기는 뭐 하는 곳이야?"가 된다.
2. **아이가 설명할 수 있는 관계** — "쉼터는 **가까이 사는 사람이 찾아가는 곳**이라, 집 가까이 공원을 두면 거기 모이고 멀리 두면 아무도 안 온다"(거리와 이용의 관계). 이 관계는 이미 셈(집 카드 '쉴 곳이 가까워요/멀어요')에 있는데, 지금은 눈으로 안 보인다.

| 19시대 걷는 사람의 목적지 섞임(`__destMix`) | 장보기 22 · 놀이 11 · **쉼 4** · 배움 4 |

**왜(코드):**
- `pickDestination` 은 셋 중 둘꼴로 '볼 일'(필요 건물 옆 길 칸)을 고른다. 그런데 **시간대 끌림 `hourPref` 의 '쉼'은 19~21시뿐**이다. 밤은 20시부터라(`isNightHour`) 사실상 귀갓길 한 시간과 겹친다.
- 목적지 칸에 닿으면 `tryEnter → buildingBeside` 가 **그 칸 둘레의 첫 필요 건물**(+x, −x, +y, −y 차례)에 들어간다. 그래서 '쉼'을 골라도 곁의 꽃밭에 들어가기 쉽다. 꽃밭은 칸 수가 많아 쉼 방문을 거의 다 가져간다.
- 들어간 사람은 곁 자리(ACT-BESIDE)에 **혼자 선다**. 같은 쉼터에 여럿이 모이는 까닭이 없다.

## 무엇을 하나 — `[ACT-STROLL]` (스위치 `VRULES.stroll` · 분류 '연기' 아님 → **'판정'**(방문 셈이 바뀜))

| | 정하는 것 |
|---|---|
| **누가** | 집에 있거나 떠도는 **어른**(일터 시각 아님 · 손님·이사 오는 사람·아이 뛰기 제외). 하루 한 번까지. 고르는 것은 **정해진 차례**(집 번호 · 날 해시) — 난수 0 |
| **언제** | **오후 15~18시**(일 끝난 뒤 · 장보기 앞). 비 오는 날·축제 날은 쉼(각자의 연기가 먼저) |
| **어디로** | 집에서 길로 `R.near`(예: 12칸) 안의 **쉼터** — 긴의자·짧은 의자·정자·마을 나무·연못·분수. 고를 때 **이미 누가 있는 쉼터에 가산점**(자리가 남았으면) → 둘셋이 모인다. 가까울수록 먼저(거리와 이용의 관계가 그대로 보이게) |
| **들어갈 곳** | 고른 **그 쉼터**에 들어간다(`buildingBeside` 의 첫 이웃이 아니라). 곁 자리가 앉는 자리면 앉고, 나무·연못이면 둘레에 선다. 마주 보게(ACT-SPACE face) |
| **얼마나** | 판 속 20~40분(정해진 차례) · 나올 때는 집으로 |
| **자리 모자람** | 긴의자 자리(3)가 차면 곁에 서고, 셋 넘게 서면 다음 쉼터로 |

마을 나무는 필요(`need`)가 없어 지금은 들어갈 수 없다(들어가면 '쫓겨남'). 이 판 전용 모습이므로 `stroll.spots` 목록에 **이름으로** 넣어 산책 목적지로만 쓴다. 판정 필요는 여전히 없다.

## 판정에 미치는 것 (예상)

- **바뀌는 것**: 쉼터 방문 셈(`f.visits` → 좋아하는 곳 `favPlace`) · 오후 길 위 사람 수(붐빔 셈이 조금) · 난수 소비 순서.
- **안 바뀌는 것(설계로 막음)**: 만족(`computeSat` 은 거리로 셈 — 방문과 무관) · 이사 판정 · 인구 문턱 · 저장 형식.
- **난수**: 산책을 고를 때 `simRand` 를 **부르지 않는다**. `pickDestination` 은 원래대로 난수를 다 쓴 뒤 목적지만 바꾼다(순서가 안 밀리게 — SITBY 의 흔들림은 여기서 났다). 들어갈 때·나올 때의 난수 소비는 보통 들르기와 같은 횟수로 맞춘다.

## 재는 법 (구현 PR 에 붙일 것)

1. **기준 ①** 스위치 켬/끔: pop88 · `--stage origin` · `--stage farm --save mid36` · 2일 · **시드 1-10**. 차이가 **설명되는 쪽**(쉼터 가까운 집의 방문↑)인지, 부호가 흔들리는지 본다.
2. **공원 화면**(origin · 헤드리스 · 15~18시 · 2배속): 쉼터별 **머문 사람 수** · **동시에 2명 이상 모인 쉼터 수(무리)** · 앉음 누적 · 사진 두 장(켬/끔).
3. **거리와 이용**: 쉼터에서 가까운 집(≤6칸)과 먼 집(>12칸) 식구의 산책 횟수 비.
4. **사냥 하네스** 판 일곱(오래 포갬 — 모여 앉은 무리가 포개지지 않나).
