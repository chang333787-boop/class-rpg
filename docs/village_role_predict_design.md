## 0. 한 줄

판 카드 7칸('나는 누구이며 무엇을 결정할 수 있나')은 지금 **설계 문서에만** 있습니다. 게임 화면에는 '할 일(질문)·목표'만 보이고 **'나는 누구'가 없습니다.**

→ 판 파일에 `역할` 한 칸을 두고, 시작 카드·위 띠·끝 카드 **세 곳에서 같은 말**로 보이게 합니다.

수업 판에는 두 가지를 더합니다.
- 시작 카드에 **예상 한 번 고르기(L2)**
- 끝 카드에 **예상 ↔ 결과**와 **처음 선택 ↔ 두 번째 선택(L8)**

셋 모두 **판정 0 · 마을 저장본 0 · 원격 동기 0**입니다. 늘어나는 것은 판 카드 기록(`rpg.stagecard.<sid>.<판>` · 로컬 전용) 두 칸뿐입니다. 이것은 저장 모양이 바뀌는 일이라 **보스 승인 뒤**에 합니다(무한 모드의 멈춤 조건).

## 2. 역할 — 판 파일 한 칸, 화면 세 곳

### 2-가. 판 파일 `역할` (안)
```json
"역할": {
  "나는": "동네 사람들이 모두 쓰게 챙기는 사람",
  "정한다": [ { "말": "무엇을 어디에 놓을까", "놓기": ["clinic", "shop", "play", "bench", "library"] } ],
  "못한다": "가게 물건 값·수는 이번엔 정하지 않아요"
}
```
- `나는` — 아이 말로 한 마디입니다.
- `정한다` — 한두 개입니다. `말`은 아이에게 보이는 물음이고, 나머지는 **그 결정을 하는 행동과 대상**입니다(`놓기`·`잇기`(길)·`고르기`(결정 칸)). 기계가 볼 수 있는 꼴이라 판 검사가 약속을 확인합니다(2-라).
- `못한다`(선택) — 엔진 정본 5번 **'이번엔 안 보여 주는 것'**을 아이 말로 옮긴 것입니다. 다음 판에서 드러낼 것을 미리 알려 줍니다.

### 2-나. 판마다 (제안 — 교사 말로 다듬을 것)

| 판 | 나는 | 정한다 | 근거(할 수 있는 행동) |
|---|---|---|---|
| town3 · town3-origin | 동네 사람들이 **모두 쓰게** 챙기는 사람 | 동네 의원·가게·놀이터·쉴 곳을 **어디에** 놓을까(09-24 PR 3a · 옛 '우물') | 트레이 시설 카드 · 목표 '주민이 쓸 수 있는 …' |
| farm | 밭에서 **가게까지 곡식이 오게** 하는 사람 | 밭을 어디에 · 가게까지 길을 어떻게 | 밭·헛간 카드 · 흐름(밭 → 가게) |
| city | **높은 동네**를 짓는 사람 | 아파트·학교·큰길을 어디에 | 아파트·학교·큰길 카드 |
| sea | 바닷가에 **부두와 가게**를 여는 사람 | 부두를 물가 어디에 · 가게까지 길을 어떻게 | 부두(물가에만) · 흐름(부두 → 가게) |
| mountain | **좁은 골짜기**에 마을을 앉히는 사람 | 골짜기에 무엇을 먼저 · 다리를 어디에 | 비탈·고갯길·판 개울(곧은 곳에만 다리) |
| origin(자유) | **우리 마을**을 가꾸는 사람 | (자유 — 무엇이든) | 목표 없음 · 역할 줄만 보임 |
| proto-flow | 빈 가게의 **까닭을 찾는** 사람 | **한 가지만** 바꿔 보기 | 질문 ①②③ |
| proto-vote | 두 동네가 **함께 정하는** 사람 중 하나 | 동네 의원 자리 둘 중 **하나 고르기**(PR 3a · 옛 '우물') | `결정` 칸(의견 카드·후보지 둘) |

운영자·소비자 역할은 지금 엔진에 **결정할 대상이 없어**(물건이 가까운 가게부터 저절로 감) 쓰지 않습니다. `village_stage_trade_b.md` 6절과 같은 판단입니다. 물건이 둘 이상이 되는 판에서 다시 봅니다.

### 2-다. 화면 세 곳 — 같은 말
1. **시작 카드** — 🔎 질문 **위**에 한 줄을 둡니다: "🧑 오늘 나는 **동네 사람들이 모두 쓰게 챙기는 사람** — 정할 것: 무엇을 어디에 놓을까". `못한다`가 있으면 그 아래 작게: "(이번엔: 가게 물건 값·수는 정하지 않아요)".
2. **위 띠** — 📋 할 일 다시 보기 **왼쪽**에 작은 이름표 "🧑 동네를 챙기는 사람"을 둡니다(누르면 같은 시작 카드). 수업 내내 '나는 누구'가 한 줄로 남습니다. 긴 이름은 `나는`의 앞 여덟 글자.
3. **끝 카드** — 지금의 '새로 생긴 것' 아이콘 줄에 제목을 붙입니다: "🧑 **내가 정한 것**: 💧×2 🛒 🛝 …". 💭 되돌아보기는 그대로입니다.

### 2-라. 약속을 지키는 장치 — 판 검사
`stages.mjs` 에 한 줄을 더합니다. `역할.정한다`의 행동마다 **그 판에서 실제로 할 수 있어야** 합니다.
- `놓기` 의 종류는 모두 그 판 `건물` 목록에 있어야 합니다.
- `잇기`면 `road` 가 있어야 합니다.
- `고르기`면 `결정` 칸이 있어야 합니다.

아니면 FAIL 입니다(화면이 **지킬 수 없는 약속**을 막음 — 36-ⓑ85 '따를 수 없는 말'과 같은 부류).

역할 칸은 **판정 0**(분류 '보기') · 저장 0 입니다.

### 2-마. 두 문장
> ① **아이가 새로 즐기거나 선택할 수 있는 것** — "오늘 나는 ___다"를 알고 들어가니, 트레이 카드가 '아무거나 놓기'가 아니라 **내가 맡은 결정**으로 읽힙니다. 판마다 다른 사람이 되어 봅니다.
> ② **학생이 설명할 수 있게 되는 사회적 관계** — *"같은 마을에서도 사람마다 정할 수 있는 일이 다르다 — 주민은 어디에 살지, 함께 정하는 사람은 하나를 고르고, 가게를 여는 사람은 어디에 열지를 정한다."* (누가 무엇을 결정하는가)

## 3. 예상 남기기 (L2)

### 3-가. 판 파일 `예상` (안)
```json
"예상": {
  "물음": "우물을 어디에 놓으면 가장 많은 집이 쓸까요?",
  "보기": ["큰길 한가운데", "집이 모인 골목 끝", "마을 가장자리"],
  "결과": { "셈": "hook", "훅": "다있음%" }
}
```
- **시작 카드**: [시작] 앞에 보기 셋 + **'모르겠어요'** 중 하나를 고릅니다(누르면 [시작]이 밝아짐). **건너뛰기**도 둡니다(수업 속도 · 교사 판단).
- 고른 것은 판 카드 기록에 `예상: { 고름: 1, t }`로 남습니다(로컬 · 마을 저장본 아님).
- **끝 카드**: "처음 예상: **집이 모인 골목 끝** → 결과: 🎯 3/4 · 💧 모두 쓰는 집 86%" + 💭 "맞았나요? 달랐다면 왜일까요?".
- **엔진은 맞다·틀리다를 매기지 않습니다.** 답이 여럿이고, 판정을 넣으면 '정답 맞히기'가 되어 설명이 사라집니다. `결과`는 결과 줄에 무엇을 적을지만 정하며, **목표 셈 꼴을 그대로 씁니다**(kind · pop · hook — 새 셈 0).

### 3-나. 두 문장
> ① 내 짐작이 맞았는지 **맞혀 보는 재미** — 시작하자마자 '내 생각'이 생깁니다.
> ② *"나는 ___라고 생각했는데 실제로는 ___였다 — 왜냐하면 …"* — 예상과 결과를 견주어 **까닭을 설명합니다**(수업 흐름 ③④).

## 4. 두 선택 나란히 (L8)

### 4-가. 무엇이 막나
↺ 처음부터가 판 카드 기록까지 지워, **처음 시도(오늘 사진·결과·예상)가 사라집니다.** 그래서 끝 카드에는 '첫날 ↔ 오늘'만 있고 **'처음 선택 ↔ 두 번째 선택'이 없습니다.**

### 4-나. 안
- ↺ 처음부터는 **마을 저장본만** 지웁니다. 판 카드 기록은 지우지 않고 **지난 시도 한 칸**으로 옮깁니다.
  - 꼴: `지난: { 사진, 셈, 인구, 예상, 목표수, t }`
  - 한 칸만 둡니다. 셋째 시도는 둘째를 덮습니다. 사진은 JPEG 320×180 ≈ 20~40KB 입니다.
- **끝 카드**에 지난 시도가 있으면 **"처음 선택 ↔ 두 번째 선택"** 두 장을 나란히 둡니다(지금 '첫날 ↔ 오늘' 자리).
  - 결과 줄 둘, 예상 둘을 함께 적습니다.
  - 그 아래 💭 "무엇을 바꿨더니 무엇이 달라졌나요?".
  - 정치 프로토 15·17회에서 나란히 보기가 효과 있었습니다.
- **교과 없는 판**(proto-flow · proto-vote)에도 끝 카드가 뜨게 합니다. 판 파일에 `끝카드: true` 가 있거나 `되돌아보기`가 있으면 됩니다(지금은 교과 칸이 조건).

### 4-다. 저장 — **보스 승인 필요**
- 늘어나는 것: `rpg.stagecard.<sid>.<판>` 에 **`예상`·`지난` 두 칸**입니다.
- **마을 저장본(SAVE_V 2)·원격 동기(sync.js)·Firebase 는 0**입니다. 판 카드 기록은 지금도 로컬 전용입니다.
- 용량: 사진 셋(첫날·오늘·지난)이면 약 100KB, 판 열 개면 약 1MB 로 localStorage 안에 들어갑니다. 넘치면 지금처럼 사진만 빼고 적습니다(`scardSave` 의 catch 그대로).
- 옛 기록(두 칸 없음)은 그대로 열립니다(없으면 없는 대로 — 지금 카드와 같음).
- **↺ 처음부터의 뜻이 바뀝니다**: '다 지움' → '마을만 지우고 지난 시도는 남김'. 교사가 판 카드까지 지우려면 따로 한 단추('기록까지 지우기')를 둡니다. 교사용 한 줄 설명이 필요합니다.

### 4-라. 두 문장
> ① 두 번 해 본 것을 **한 화면에서 견준다** — "이번엔 여기에 놓아 볼래"가 놀이가 됩니다.
> ② *"같은 마을에서 **선택만 바꾸면** 결과가 달라진다 — 우물을 골목 끝에 놓았을 때 9채, 큰길 가운데는 5채"* — 원인과 결과를 **선택으로 가릅니다**(수업 흐름 '비교' 칸 · L1 과 한 쌍).

## 5. 순서 (제안)

1. **역할 칸** + 시작 카드 한 줄 + 위 띠 이름표 + 끝 카드 제목 + 판 검사(2-라). **저장 0**이라 가장 작습니다. 판 파일 여섯(town3·town3-origin·farm·city·sea·mountain)에 먼저 넣습니다.
2. **예상 고르기(L2)** — 판 카드 기록 한 칸(`예상`)이 늘어서 승인 뒤에 합니다.
3. **두 선택 나란히(L8)** — ↺ 처음부터의 뜻이 바뀌어서 승인 뒤에 합니다. 교사 설명 한 줄을 붙입니다.

단계마다 다음을 확인합니다.
- **village-look `--ui`**(카드가 보이게)로 시작·끝 카드 사진을 찍습니다.
- 기준 ① 0 · 판 검사 PASS 여야 합니다.
- 카드 글이 run.mjs 가 세는 글(JW_TXT · '길이 붐벼요' · '😊')과 겹치지 않게 합니다.

## 6. 보스가 정할 것
1. 판 파일 `역할`(나는·정한다·못한다) 꼴과 판마다 문장(2-나 표) — 교사 말로 다듬을지.
2. 예상: 보기 셋 + '모르겠어요' · 건너뛰기 허용 · **맞다/틀리다를 매기지 않음** — 동의하시는지.
3. L8: ↺ 처음부터가 판 카드 기록을 **남기는** 쪽으로 바꿔도 되는지(지금은 지움) · 지난 시도는 한 칸.
4. proto-flow·proto-vote 에 끝 카드(`끝카드: true`).

## 미검증
- 실제 아이가 역할 줄을 읽는지, 예상 고르기가 수업을 늦추는지 — 교실에서만 답이 납니다.
- 판별 역할 문장은 제 안입니다. 교과서 낱말과 대조하지 않았습니다.
- L8 의 '나란히'가 1366 화면에서 두 장 + 결과 둘을 한 카드에 담을 수 있는지 — 구현 때 `--ui` 사진으로 봅니다.
