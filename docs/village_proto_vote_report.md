## ① 실행 경로

```

```

- 판 파일 `village/stages/proto-vote.json` · 시작 저장본 `village/stages/starts/proto-vote.json`.
- 저장 키 `rpg.village.<sid>.proto-vote` · 원격 동기 꺼짐 · 운영 DB 접촉 0.
- 본편 화면에 이 판으로 가는 **버튼은 없다** — 주소로만 연다. 판 파일에 `결정` 칸이 없으면 `[MAC-VOTE]` 블록은 통째로 잠잔다(본편은 한 줄도 안 달라진다).
- 되돌리기: **[다시 살펴보기]** — 저장본을 지우고 판의 `시작` 저장본으로 다시 연다.

## ② 해 볼 행동

열면 **두 안이 이미 나란히 재어져** 있다 → 두 동네의 이유 카드를 읽는다 → [A안/B안 미리 보기]로 하나를 고른다 → [이 안으로 결정 적용] → 소식에서 **기뻐진 쪽과 남는 쪽을 함께** 본다 → [다시 살펴보기] → 다른 안 적용 → [💭 되돌아보기] 세 질문.

## ③ 완료 시험 (정본 3절) — 전부 통과

크롬북 실뷰포트 **1366×610** 실화면.

| 시험 | 결과 |
|---|---|
| 두 안을 미리 본 값이 **실제 판정과 일치** | A 윗4/0·아랫0/4 · B 윗1/3·아랫3/1 → 적용 뒤 **8/8 일치**(수뿐 아니라 이름 목록까지) |
| 미리 보는 동안 세계가 안 바뀜 | 지문(배치+집+인구) 불변 · 우물 0 |
| 되돌리면 앞 실행의 흔적 0 | 지문 `493:ho7cby` · 인구 16 · 층[8,0,0] · 8집 전부 '물 멀다' · 놓은 것 71→70 |
| 다른 안 적용도 같은가 | B 적용도 8/8 |
| 승패로 처리하지 않음 | 정답 후보지 없음 · 총점 없음 · 축하 연출 없음 · **남는 불편이 가까워진 쪽과 같은 크기·같은 자리**에 이름까지 |

**판이 일부러 4:4 다.** 총계만 보면 "둘이 같네"로 끝나고, 실제로 갈리는 것은 **누가**다 — 그것이 이 판의 요점이다.

## ④ 화면 증거

결정 전(두 안 나란히) · A 적용(✅ 실제 + 👀 적용 전에 미리 본 B값 + 🙍 남는 불편 소식) · 되돌린 뒤(시작 상태) · B 적용 · 빈 탭 안내 — 실화면에서 확인.

## ⑤ 미검증

- 실제 학생이 "수는 같은데 사람이 다르다"를 스스로 말하는지.
- 실물 크롬북(크기만 맞췄고 기기는 아니다).
- 3분 넘는 관찰 — 집이 자라고 인구가 느는 구간은 실시간으로 못 봤다.
- **민주주의 학습 효과는 검증하지 않았다.**

## ⑥ 본편 반영 판단

### 가져갈 것
1. **가정한 배치에 기존 판정을 그대로 돌려 미리 보기.** 쓰기 0 으로 되고, 적용 값과 8/8 맞았다. 본편 '놓기 전 미리 보기'의 정직한 토대다.
2. **지문(배치+집+인구)으로 "안 바뀌었다"를 재는 습관.** 값이 싸다.
3. **되돌리기 = 시작 저장본에서 다시 열기.** 부분 되돌리기보다 흔적 0 보장이 확실하다.
4. **좋은 일과 남는 불편을 같은 통로로 한 번씩.**

### 버릴 것
1. **겹판 칠하기** — 놓기 모드 밖에서는 기존 `__overlay` 조차 안 보인다. 보이게 하려면 공유 렌더링을 손대야 한다.
2. **시작 저장본에 방해 알림을 하나씩 끄는 방식** — 목표·해금·땅이 매번 새로 샌다. **판 파일에 "이 판은 조용히" 스위치가 필요하다.**
   → 이것이 다음 일로 나갔다: 엔진 정본 2번 칸(판 파일이 판정 규칙을 실제로 끄기).

### 결정이 필요한 것
1. **두 동네가 한 화면에 안 들어온다** — 사거리 14칸 때문에 30칸을 띄웠고, 「판 전체 보기」는 지도라 너무 멀다. 본편에 '두 곳 함께 보기' 카메라를 둘 것인가.
2. **적용 뒤 윗마을 세 집에 `길이 붐벼요`+`🛣️ 큰길로 넓혀 봐요`** 가 붙는다(모두 우물로 걸어가서). 세계의 정직한 반응이지만 정치 수업에서는 눈을 끈다.
3. **집 성장·인구 증가를 판 단위로 멈출 스위치** — 이번엔 안 만들었고, 관찰이 3분을 넘으면 비교가 흐려진다. (위 '버릴 것 ⑵'와 같은 스위치다.)
4. **제3의 자리(140,125)면 5집이 닿는다** — "두 안 중 고르기"라는 틀을 언제 풀 것인가.

## ⑦ 보스 검증에서 고친 것 하나 (기록해 둘 교훈)

ⓑ12('남는 불편도 한 번')를 `simSay` 로 넣었더니 **운에 따라 되살아났다.** `simSay` 는 '되풀이되는 소식' 줄(한 칸)이라, 적용 직후 세계가 `🎉 ○○네가 기뻐해요`를 말하면 **새것이 앞엣것을 대신한다**(`[MAC-TOASTQ]` 덧 2). 실제로 한 판은 🙍 가 떴고 다른 판은 🎉 만 떴다 — 고치려던 '1 대 0'이 그대로 돌아온 것이다.

이 소식은 그 판에서 **다시 오지 않으므로** `sayOnce`(버리지 않고 쌓아 두는 줄)로 옮겼다. 실측 `한번뿐 1 · 밀림 0` · 두 판 모두 🙍 표시.

> **교훈:** 한 번 돌려 보고 "뜬다"로 적지 않는다. 말자리는 한 칸이라 **무엇과 겹치느냐**에 따라 결과가 달라진다. 다시 안 오는 소식은 `sayOnce` 로 낸다.
