## 하루 흐름 (js/today.js — 화면 없는 순수 로직 · 시험 scripts/unit/mathgap/today.test.mjs)
1. 처음이면 **하는 법**(그림 셋: 살펴보기 · 불 꺼진 층 · 불씨) — 한 번만, 뒤로는 화면 위 ? 단추
2. 이 단원을 아직 안 살펴봤으면 **탑 살펴보기** = 단원 점검(갈래 맨 위부터 → 반씩 좁혀 경계 → 아래로 DAG 반씩 좁히기). 맞고 틀림은 끝에 탑으로 한꺼번에
3. 불 꺼진 층을 **기초부터 → 아래층부터** 하나씩: 층마다 하는 법 한 줄 → 문제(거꾸로 세는 원 · 불씨) → 틀리면 **같이 풀기**(같은 숫자로 한 단계씩, 시간 안 잼)
4. **불 점검(간격 복습)** — 켠 층마다 점검 날이 있다: 연습으로 켠 층 1일 · 살펴보기에서 직접 맞힌 층 7일 · 미루어 안 층 3일 뒤. 한 번에 맞히면 다음 간격(1 → 3 → 7 → 14 → 30일), 다시 해서 맞히면 같은 간격, 두 번 틀리면 그 층 불이 꺼짐. 위층을 맞히면 그 아래 켜진 층은 복습한 셈(점검 날을 뒤로). 점검 날이 된 층이 있으면 그날 맨 앞에 몸풀기 — 아직 켤 층이 있는 날 2문제, 탑 완성 뒤 3문제
5. 하루 시간(기본 10분 · 선생님이 5/10/15/20)이 차면 '오늘 끝' — 아이가 '5분만 더'를 누를 수 있음. 문항마다 저장 → 다음에 열면 같은 문제로 이어서
- 화면 위 **'지금 할 일'** 줄이 늘 있다(금색 = 연습 · 파랑 = 같이 풀기 · 초록 = 끝)

## 저장 (classRPG_mathgap — store.js)
- `config` { unit, minutes, t } — 쓰기는 선생님 화면만
- `kids/<sid>/` st(차시 상태) · scans(단원별 살펴보기 요약) · marks('선생님과') · rev(간격 복습 표) · bugs(틀린 모양 '차시|이름' → 수, 40가지까지) · run(하던 세션) = **JSON 글**(세션 안의 빈 배열 · null 이 RTDB 에서 사라지지 않게) · days/<날짜> { ms, n, lit, review, extra } · seen { intro } · card(홈 카드 · 선생님 표 요약)
- **이름은 저장하지 않는다** — 학급 DB 는 로그인 없이 읽힌다. 선생님 화면은 반 명단(common/roster.js)에서 이름을 붙인다.
- 읽은 값은 모양을 거른다(kidFrom · cleanCfg). 날짜 기록은 30일만.
- **쓰기 전에 undefined 를 거른다**(clean) — RTDB 는 값 안에 undefined 가 하나라도 있으면 쓰기 전체를 거절한다(10-10 가짜 RTDB 에서 찾음: 불 점검을 이어서 할 때 카드 칸 하나가 비어 그날 저장이 모두 빠짐 → 시험 '어느 단계에서도 빈 값이 없다')
