## 2. 색 엔진(`paint/js/color.js` · DOM 없음)
- **섞기 = RYB 큐브**(Gosset & Chen 2004, '물감처럼 섞이는 색' — 파랑 + 노랑 = 초록). 빛의 섞기(RGB)를 그대로 쓰면 파랑 + 노랑이 회색이 된다. 큐브 뼈대 그대로 · 모서리 색만 화면 형광색(#ff0000 · #ffff00)에서 학교 물감 쪽으로 낮춤.
- 색 물감끼리는 **비율**(가장 많은 것 = 1)로 큐브 → 그다음 흰색 · 검정을 무게대로. **검정은 한 방울이 두 방울 힘**(조금만 넣어도 확 어두워지는 진짜 물감처럼). 그래서 두 배로 넣어도 같은 색(1-8 '물감이 모자라요' 판의 뜻).
- 학교 물감 3원색 = 빨강 · 노랑 · 파랑(미술 시간 물감 상자). 인쇄 · 과학의 3원색은 자홍 · 노랑 · 청록(CMY) — 물감 연구소는 미술 시간 쪽. 화면 빛과 반대라는 것은 1-3(파랑 + 노랑 ≠ 흰빛) · 3-3(빨강 + 초록 ≠ 노랑빛) 보기에서 직접 다룬다.
- **견주기 = CIE Lab ΔE**(사람 눈에 가까운 거리). 가까움 % = 100·e^(−ΔE/44.8)(ΔE 10 = 80% = 통과) · 별 = ΔE 3 · 6 · 10.
- **무엇이 다른가**(`diffOf`) — 밝기 L · 선명함 C · 색깔 h 가운데 가장 큰 것 하나를 아이 말로. 흐려진 쪽이 흰빛이면 '탁하다'가 아니라 '밝고 연해요'(분홍 ≠ 탁한 빨강).
- **다음 한두 방울**(`judge.js nextStep`) — 그 판에 있는 물감만, 한 방울 더 · 빼기를 한 번이나 두 번 해 보고 가장 가까워지는 것. 셈으로 고르니 틀린 말이 없다(두 번까지 보는 까닭: 빨강 1 → 다홍은 '빨강 더'만으로는 비율이 같아 색이 그대로). 두 번째로 틀릴 때부터 보인다.
- **색 읽기**(`readColor`) — 가장 가까운 바퀴 칸 · 밝은/중간/어두운 · 선명한/조금 탁한/탁한/연한 · 따뜻한/차가운/그 사이. 갈색 = 어두운 주황 · 분홍 = 밝고 흐린 빨강 · 흐린 색은 '주황빛 회색'처럼.

## 3. 장 · 판(정본 = `paint/js/stages.js` · 33판)
| 장 | 물감 | 판 |
|---|---|---|
| 1 빨강 · 노랑 · 파랑 | 빨노파 | 예상(빨+노 · 파+노) · 주황 · 초록 · 보라 · 다홍(빨강 더) · 청록(파랑 더) · **물감이 모자라요**(연두를 6방울 이상 = 비율) · **색 바퀴 채우기**(귤색 · 남보라 · 자주 — 목표 숨김 · 이웃 두 칸의 사이 색 · 섞는 색이 칸에 미리 보임) → 1장을 다 풀면 **내 색 바퀴 12칸**(내가 만든 색으로) |
| 2 밝게 · 어둡게 | + 흰색 · 검정 | 예상(빨+흰 · 주황+검정 = 갈색!) · 분홍 · 연한 파랑 · 갈색 · 회색 · **진하기 띠**(가운데 파랑 그대로 · 왼쪽 연하게 · 오른쪽 진하게 — 정답 색 없이 차례 규칙으로 채점 · 칸마다 또렷이 다를수록 ★) |
| 3 마주 보는 색 | 빨노파만(검정 없이) | 보색 자리(빨강의 짝 · 짝 셋) · 예상(빨강 + 초록 = 거무스름한 갈색) · 주황을 탁하게(황토) · 초록을 탁하게(풀숲) · **가장 또렷한 바탕**(보색 대비 — 섞으면 탁 · 나란히 두면 또렷) |
| 4 자연의 색 | 다섯 | 그림 속 빈 곳 칠하기(관찰 카드 + 섞는 색이 그림에 바로): 새싹 · 노을 · 밭흙 · 바위 · 깊은 바다 · 벚꽃 |
| 5 느낌의 색 | 다섯 | 따뜻한 · 차가운 · 그 사이(중성색) 나누기 · **느낌의 색 넷**(운동회 · 비 오는 월요일 · 이불 속 · 우리 반) — 정답 없음 · 고른 까닭 칩(밝아서 · 따뜻해서 · 탁하고 수수해서 …) · **우리 반 모자이크**(내 색을 붙인 뒤에야 친구 색이 보임 · 반 정리 한 줄: '대체로 밝고 따뜻한 색으로 느꼈어요') |
- + **자유 실험실**(`#/lab`) — 판 없이 섞고, 색 읽기 · 바퀴에서 가장 가까운 칸.
- 별: 섞기 = 만든 색의 가까움 · 고르기 = 틀린 수(0 → ★★★ · 1~2 → ★★ · 그 뒤 ★) · 바퀴 채우기 = 칸 별의 평균 · 진하기 띠 = 이웃 칸 밝기 차이의 최소. 순위 · 골드 없음. 장 안에서 앞 판을 풀어야 다음 판.

## 4. 시중 프로그램이 못 하는 것
1. **틀린 까닭을 이름으로** — '밝기가 다름 · 선명함이 다름 · 색깔이 다름 · 양 · 비율 · 섞기 예상 · 보색 자리 · 따뜻함 · 진하기 차례'를 센다 → 선생님 헷갈림 지도(아이마다 · 반 전체).
2. **정답 물감을 다 써야만 통과하는 판** — 3장은 검정 없이 보색으로 탁하게(시험이 '정답 물감 없이 통과하는 섞기'가 없음을 모든 섞기를 다 돌려 지킨다). 2장 갈색 · 회색은 길이 여럿인 것도 정답(세 색 섞기 갈색 · 세 색 + 흰색 회색).
3. **정답 없는 판을 반 기록으로** — 느낌의 색 모자이크 + 까닭 칩 + 셈으로 낸 반 정리. 선생님 화면에는 이름과 함께.
4. **내 색이 남는다** — 1장에서 만든 내 색으로 홈의 색 바퀴가 채워진다 · 선생님 표에 아이가 만든 색 동그라미.
5. 색약인 아이도 — 가까움 % · '무엇이 다른가' 말 · 다음 한두 방울이 눈 대신 길을 알려 준다.

## 5. 저장(`classRPG_paint` · 무늬 공방과 같은 꼴)
- `progress/<sid>/<판>` = { st, n, t, c(내가 만든 색 · 바퀴 · 띠 판은 [색…]) } · `stats/<sid>/<판>` = { tries, ok, light · chroma · hue · amount · pick · wheel · contrast · sort · order } · `names/<sid>`.
- `feel/<판>/<sid>` = { c #rrggbb, w 칩 'bright,warm', t } — 글 입력 없음. 학급 DB 는 열려 있어 그리기 전에 거른다(`cleanFeel`: #rrggbb 만 · 아는 칩만 · 둘까지).
- 손님(sid 없음)은 이 기기 localStorage. RPG 본 데이터는 안 건드림(선생님 비밀번호 확인 한 번 읽기만). 보상과 묶지 않음.
