## 2. 보스가 물은 다섯

### 2-가. 동네를 무엇으로 가르나 — **`동네` 칸을 그대로 쓴다. 한 칸만 더한다**

✅확인: `proto-flow.json` 이 이미 판 파일에 `동네` 칸을 쓴다.
```json
"동네": [ { "이름": "밭 마을", "가운데": [155, 138], "반지름": 7 },
          { "이름": "가게 마을", "가운데": [135, 139], "반지름": 9 } ]
```
코드가 이 칸을 읽는 곳은 `[MAC-PROTOMAP]` 한 곳이다. 동네 안인가는 `pmapIn` 으로 본다 — 가운데에서 가로·세로로 반지름 안의 **네모**다.

**💭제안: 각 동네에 `건물` 목록 하나를 더한다.** 판 전체 `건물` 과 같은 꼴이다.
```json
"동네": [ { "이름": "농촌 동네", "가운데": [155, 138], "반지름": 7, "건물": ["road","field","well","tree","flower"] },
          { "이름": "도시 동네", "가운데": [135, 139], "반지름": 9, "건물": ["road","house","shop","well","play","bench","tree","flower"] } ]
```
- **놓기 막기 한 고리**: 지금 판 `건물` 을 읽는 `canPlace` 고리(✅ `STAGE.def.건물` → '이 판에서는 쓰지 않아요')와 같은 자리다. 놓는 칸(발자국 전부)이 어느 동네 안이면 그 동네의 목록도 본다.
  막을 때의 말은 **그 건물이 놓이는 동네 이름**을 말한다 — 「밭은 **농촌 동네**에 놓아요」. '안 된다'가 아니라 '어디로 가라'다(3번 완료 시험의 재료).
- **동네 밖**(두 동네 사이 · 네모 바깥)은 판 전체 목록만 본다. 두 동네를 잇는 길은 거기에 놓인다.
- 동네 네모가 겹치면 **먼저 적힌 동네**가 이긴다(판 검사가 겹침을 REVIEW 로 알려 주면 좋다).
- 분류: **'조작'**(놓기 막기) — 판정 수에 안 든다. 판 검사(`stages.mjs`)는 '동네 `건물` 목록이 판 전체 목록 안에 있나'를 본다.

**⚠ 걸리는 것 — `동네` 칸이 있으면 작은 모형 화면이 켜진다** ✅확인. `pmapLive()` 는 `동네` 가 둘 이상이고 `VRULES.protoMap.on` 이면 참이다. 그러면 [🗺️ 고장 전체] · [밭 마을] · [가게 마을] 단추와 **모형 Scene** 이 선다.
조사 4절의 결론은 **모형 화면은 버린다**였다. 그래서 이 판은 `규칙: { "protoMap": { "on": false } }` 로 끈다.
이러면 동네 사이를 오가는 **카메라 단추도 같이 꺼진다**. 오가는 길은 **데려가기(2-다)** 와 미니맵이 맡는다. 단추만 살리고 모형을 끄는 스위치는 지금 없다 — 필요하면 보스가 정할 것(6절).

### 2-나. 판 하나 한 주제 — **수용량은 끈다. 일자리·붐빔도 끈다**

✅확인(판 검사): 수용량(`shopCap`)은 **조건부 판정**이다 — `정원` 이 적힌 건물(도시 판 `store` 의 `정원: 6`)이 있을 때만 돌고 판정 수에 든다. 기본 `shop` 은 정원이 없다.
- 이 판은 기본 `shop` 을 쓰므로 **적지 않아도 수용량은 안 돈다.** 그래도 `"끄기": ["수용량"]` 을 **적는다** 💭. 뒤에 누가 정원 있는 가게를 판에 더해도 두 번째 까닭(꽉 찼어요)이 몰래 켜지지 않게 하려는 것이다. 수용량 설계 #810 1-라의 말대로 교류는 ③(물건) 층이고 ②(자리) 층은 마을 안의 일이다 — **첫 판에서 두 층을 한 화면에 세우지 않는다.**
- **일자리·붐빔도 끈다** 💭 — `"끄기": ["일자리","붐빔","수용량"]`. 켜진 판정은 **6 → 2**(`manyLibrary` · `turnAway`)가 된다. town3 이 이미 이 꼴로 판 검사를 통과했다 ✅(끄기 뒤 2).
  까닭: 도시 동네 집이 20명을 넘으면(`JOB_POP` 20 ✅) '일할 곳이 멀어요'가 뜬다. 농촌 동네 밭은 일자리가 아니다(`field` 에 jobs 없음 ✅). 그러면 아이가 **빈 선반과 일자리 걱정을 한꺼번에** 따진다. 이 판의 주인공은 흐름 하나다.
- 남는 `turnAway`(필요가 모자라 돌아섬)는 도시 동네의 우물·놀이·쉼으로 푼다. 시작 땅에서 이미 채워 두어(4절) **처음에는 걱정 풍선이 빈 선반 하나뿐**이게 한다.

### 2-다. 권유가 동네를 말하기 · 데려가기가 동네를 넘기

**지금** ✅확인(#816 뒤 main):
- 빈 가게 까닭은 **값** 넷이다(`flowWhyCode` → coming · cut · none · growing). 말은 그 값에서 만든다.
  cut 「밭에 쌓여 있는데 길이 끊겼어요」 · none 「이 가게에 오는 밭이 없어요」 · growing 「밭이 아직 자라는 중이에요 — 밭을 더 만들어 볼까요?」
- 누를 때 짚는 곳(`whereSpots`)은 **cut 일 때만** 있다. 끊긴 밭에서 가게 쪽으로 되짚어 **이어야 할 길 칸**을 반짝이고, 그 칸이 화면 밖이면 카메라를 옮긴다. none·growing 은 짚는 곳이 없다.

**B 에서 생기는 어긋남**: 도시 가게가 「밭을 더 만들어 볼까요?」라고 하는데 **도시 동네엔 밭을 못 놓는다.** 아이는 가게 곁에 밭을 놓으려다 막힌다.

**💭제안 — 값은 그대로 두고, 말과 짚기에만 '동네'를 붙인다**(값 → 말·그림 갈래를 그대로 쓴다)

| 까닭 값 | 말(지금 → B) | 짚는 곳(지금 → B) |
|---|---|---|
| cut | 「밭에 쌓여 있는데 길이 끊겼어요」 그대로 | 끊긴 칸 그대로 — 두 동네 **사이** 길이면 카메라가 **동네 경계를 넘어** 그리로 간다(지금 코드 그대로 된다 ✅ `whereGo` 는 칸이 화면 밖이면 옮긴다) |
| none | 「이 가게에 오는 밭이 없어요」 → 「… — **농촌 동네**에 밭을 놓아 볼까요?」 | 없음 → **농촌 동네에서 밭을 놓을 수 있는 칸** 하나(동네 가운데에서 가장 가까운 곳) |
| growing | 「밭이 아직 자라는 중이에요 — 밭을 더 만들어 볼까요?」 → 「… — **농촌 동네**에 밭을 더 만들어 볼까요?」 | 없음 → 위와 같음 |
| coming | 「곧 와요 — 오는 중이에요」 그대로 | 없음(수레가 보인다 · #827) |

- **'농촌 동네'는 어떻게 고르나**: 판 `동네` 가운데 **`건물` 목록에 만드는곳 종류(`field`)가 든 동네**다. 이름은 그 동네의 `이름` 이다. 그런 동네가 없는 판(농촌·바닷가·산지·기본)은 **한 글자도 안 바뀐다** — 권유 끝에 붙일 동네가 없기 때문이다.
- 짚는 칸은 **하나만**이다(프로토 ⑥의 조건 ② '후보를 여럿 반짝이면 헷갈린다'). 누른 것에만 짚는다(조건 ①).
- 🔶 **데려가기가 '넘는' 것의 뜻**: 저장본이 하나라 동네 경계는 **카메라 이동일 뿐**이다. 짝 판(C · 11월)이면 남의 마을은 고칠 수 없어 **관문에서 멈추고 알려 주기**로 바뀐다(조사 4절). B 에서는 넘어가도 된다.

## 3. 코드가 부르는 것 (구현 담당에게 · 작은 순서)

1. **`동네[].건물`** — canPlace 고리 하나 + 막을 때의 말(동네 이름). 판 검사: 동네 목록 ⊂ 판 목록 · 동네 네모 겹침 REVIEW.
2. **권유 끝의 동네 이름** — `flowWhyEmpty` 의 none·growing 두 갈래 끝에 `(동네 있으면) '— ' + 이름 + '에 …'`. 값(`flowWhyCode`)은 안 바뀐다. 그래서 팻말 그림(`fsWhy`)도 안 바뀐다.
3. **짚기** — `whereSpots` 의 빈 가게 갈래에 none·growing 을 더한다 → 그 동네에서 `canPlace('field')` 가 참인 칸 가운데 가운데에서 가장 가까운 한 칸.
4. **`받은세대%` 훅** — `STAGE_HOOKS` 에 한 줄. 사는 집이 없거나 흐름이 꺼져 있으면 null.
5. 판 파일 둘 + 판 검사 통과. `규칙: { "protoMap": { "on": false } }`.

**연기(주민 연기 담당 · 구현 뒤)**: 수레(#827)가 두 동네 사이 28칸을 간다. 이 판의 `칸당틱` 13이면 364틱 ≈ 36초다. 수레가 **동네 경계를 넘는 순간**이 교류가 보이는 자리다 — 새 그림 없이 지금 수레로 되는지 실화면으로 본다.

## 4. 시작 땅 — 한 원인씩 차례로 (💭)

`proto-flow` 시작 땅을 바탕으로 한다(두 동네 · 28칸 · 흐름이 이미 도는 판 ✅). 바꿀 것:
- **도시 동네**: 집 4(8명) · 가게 1 · 우물·놀이터·쉼터를 **이미 닿게** 둔다 → 처음 걱정은 빈 선반 하나뿐.
- **농촌 동네**: 밭 1 · 집 0 💭(아래 판단).
- **두 동네 사이 길**: **2칸이 끊긴 채**로 시작한다 → 첫 까닭은 **cut** 이고, 짚기가 도시에서 **두 동네 사이**로 데려간다.
- 이으면 곡식이 오지만 밭이 1곳이라 하루 3개다 → 도시 4세대는 못 채운다 → 두 번째 까닭 **growing** 「… — 농촌 동네에 밭을 더 만들어 볼까요?」 → 농촌 동네로 간다.
- 한 번에 한 원인이다: **잇기(길) → 늘리기(밭)**. 목표 ①(받은세대% 100)은 밭이 2곳 이상일 때 선다. 하루 6개 ≥ 4세대(프로토 2절 수치 ✅).

**농촌 동네에 집을 두나 — 💭 안 둔다(첫 판).** 집을 두면 그 집들도 장을 봐야 한다. 가게를 안 두면 「장 볼 곳이 멀어요」(필요 판정)가 뜨고, 가게를 두면 밭이 **가까운 농촌 가게부터** 채운다(✅ `flowStoresFrom` 은 가까운 순). 어느 쪽이든 두 번째 주제가 선다. 농촌에 사람이 사는 모습은 4-2 농촌 판(`farm`)의 몫으로 두고, 이 판은 '만드는 곳'으로만 둔다. 사람은 연기(밭 곁 일꾼)로 보일 수 있다 — 밭에 일자리가 없어 지금은 안 보인다(6절).

## 5. 완료 시험 (16칸 · 화면에서 볼 수 있는 말로)

| # | 시험 | 무엇으로 보나 |
|---|---|---|
| ① | **보냄 → 닿음 → 씀이 숫자로 이어진다** — 농촌 동네 밭의 곡식이 수레로 도시 가게에 닿고, 도시 세대가 쓴다 | `__flow()` 합계 검산(만듦 = 밭 + 운반 + 가게 + 씀 + 맡아 둠 · 프로토 정본 2-4) · 수레가 닿는 틱에 선반 수가 오른다(#827 시험 그대로) |
| ② | **길을 끊으면** 도시 가게 카드가 「밭에 쌓여 있는데 길이 끊겼어요」이고, 누르면 **끊긴 칸으로 데려간다**(두 동네 사이) | `__where(가게)` 의 짚을 칸이 끊긴 칸 · 카메라가 옮겨졌나(`WHERE.stats.카메라`) |
| ③ | **농촌 밭을 치우면 도시 안에서는 못 고친다 — 그리고 그것이 화면에서 읽힌다** | 셋이 **같은 동네 이름**을 말해야 선다: (a) 도시 가게 카드 「이 가게에 오는 밭이 없어요 — **농촌 동네**에 밭을 놓아 볼까요?」 (b) 도시 동네에 밭을 놓으려 하면 「밭은 **농촌 동네**에 놓아요」 (c) 가게를 누르면 카메라가 **농촌 동네의 한 칸**으로 간다. 셋 중 하나라도 '밭'만 말하고 동네를 안 말하면 FAIL |
| ④ | **저장·복원** 뒤 재고·운반 중(수레 자리)·시간이 같다 — **빈 연결로도** 한 번(아직 아무것도 안 보낸 판) | 저장 → 새로 열기 → `__flow()` · `__flowCart()` 같음. 세대 묶음의 덫(빈 것이 저장에서 빠짐)을 여기서 잡는다 |

③ 의 (b)를 시험에 넣은 까닭: 아이가 **가장 먼저 해 볼 수** — 가게 곁에 밭 놓기 — 이 막힐 때, 그 막힘의 말이 곧 답이 되어야 한다.

## 6. 보스가 정할 것

1. `동네[].건물` 로 가를지(2-가). 다른 길은 동네를 **판 둘**로 나누는 것인데, 그건 저장본 둘이라 짝 판(C)이다.
2. 모형을 끄면서 **동네 카메라 단추도 같이 끌지**(2-가 ⚠). 제안은 '끈다 — 데려가기와 미니맵으로 충분'. 모자라면 `protoMap` 에 '단추만' 스위치를 새로 둔다.
3. `"끄기": ["일자리","붐빔","수용량"]` — 판정 6 → 2(2-나).
4. **농촌 동네에 집을 안 두는 것**(4절). 두면 두 번째 주제가 선다.
5. 목표 훅 `받은세대%`(읽기)를 더할지. 없으면 목표를 `kind` 로만 세워야 하는데, '밭 3곳'은 **놓으면 끝나는 목표**에 가깝다(19회 ⓐ2).

**이 카드에 없는 것(뒤로)**: 여러 물건 · 서로 바꾸기 · 짝 판(두 저장본 · 관문) · 동네마다 색 · 통근 · 밭 곁 일꾼(밭에 일자리가 없다 — 농촌 판과 같은 물음).
