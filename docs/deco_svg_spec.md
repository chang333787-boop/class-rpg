# 장식 SVG 규격 (DECO-SVG-1)

- 작성: 2026-09-04 · 기준 코드: `student.js` `_drawDecoSVG` / `_decoImg`
- 대상: 마당·집 안 장식 69종. SVG 제작 담당(SVG 세션)과 배치 코드(보스) 사이의 계약.

## 왜 필요한가 — 지금 무엇이 잘못됐나

배치 루프가 비정사각 장식을 **비율을 억지로 늘려서** 그리고 있었다.

```js
_dCtx.scale(sz.w > sz.h ? sz.w/sz.h : 1, sz.h > sz.w ? sz.h/sz.w : 1);
```

`_dSofa`는 **이미 가로로 긴 그림**(±0.82s 폭 × ±0.6s 높이)인데, 3×1 소파라는 이유로
`scale(3, 1)`이 한 번 더 곱해진다. 결과가 3배 납작한 소파다. 세로 3칸 장미 아치는 3배 길쭉해진다.
가로등·허수아비처럼 **위로 솟아야 하는 것**도 footprint 상자 안에 눌려 담긴다.

## 어떻게 고치는가 — 데이터가 코드를 이긴다

`assets/deco/<id>.svg` 가 **있으면** 그 그림을 쓰고, **없으면** 기존 캔버스 그림을 그대로 쓴다.
즉 **SVG를 한 장 만들 때마다 그 장식 하나가 고쳐진다.** 코드를 다시 건드릴 필요가 없고,
아직 그림이 없는 장식은 지금 모습 그대로다(이번 변경으로 아무것도 안 바뀜).

배치 규칙은 세 줄이다.

```js
const w = bw;                    // 폭 = footprint 폭 (땅에 닿는 넓이)
const h = w * (nh / nw);         // 높이 = 비율 그대로. 절대 늘이지 않는다
drawImage(img, px, py + bh - h, w, h);   // 아래 끝을 footprint 바닥에 붙인다
```

## 제작 규격 (지켜야 할 것)

| 항목 | 규칙 |
|---|---|
| 경로·이름 | `assets/deco/<장식 id>.svg` — id는 `gamedata.js`의 `decorations[].id` 그대로 (`d_i8`, `d_y21` …) |
| **width/height 속성** | **필수.** `<svg width="300" height="150" viewBox="0 0 300 150">`. 이게 없으면 브라우저가 크기를 모르고, 캔버스에 **아무것도 안 그려진다** |
| viewBox 폭 | footprint 가로 칸수에 비례. 3×1이면 폭:높이 기준을 3칸으로 잡는다 |
| viewBox 높이 | footprint 높이 + **위로 필요한 만큼**. 가로등처럼 1×1인데 위로 솟는 것은 높이를 크게 잡으면 된다 |
| 원점·바닥선 | 그림의 **맨 아래가 땅에 닿는 선**이다. 그림자·다리를 viewBox 아래쪽 끝에 맞춘다 |
| 넘침 | **위로만** 넘친다. 좌우로 넘기면 옆 칸 장식과 겹친다 — 폭은 footprint 안에서 끝내라 |
| 그림체 | 두꺼운 외곽선 + 셀셰이딩 + 하이라이트 (기존 캐릭터·에셋과 같은 결) |
| 축소 검증 | 실제 셀은 일반 모드에서 **17~30px**. 24px·38px로 줄여 보고 형태가 남는지 확인할 것 |

### 예시 — 3×1 소파

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="300" height="150" viewBox="0 0 300 150">
  <!-- 바닥선 y=150. 그림자·다리를 여기 맞춘다 -->
  <ellipse cx="150" cy="142" rx="128" ry="9" fill="rgba(0,0,0,.20)"/>
  ...
</svg>
```

### 예시 — 1×1인데 위로 솟는 가로등

```xml
<svg xmlns="http://www.w3.org/2000/svg" width="100" height="260" viewBox="0 0 100 260">
  <!-- 폭은 1칸, 높이는 2.6칸 → 칸 위로 1.6칸 솟는다 -->
</svg>
```

## 배치 코드가 이미 해 둔 것

- **뒤→앞 정렬**: 윗줄부터 그린다(`_decoSorted`). 위로 솟은 장식을 앞줄 장식이 가리도록.
- **캐시**: id마다 한 번만 불러온다. 파일이 없으면 다시 시도하지 않는다(404 반복 없음).
- **비동기 안전**: 그림이 늦게 도착하면 `_drawDeco()`로 한 번 다시 그린다.
- **폴백**: 파일이 없거나 크기를 못 읽으면 기존 캔버스 그림으로 되돌아간다.
