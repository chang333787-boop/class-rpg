# 교실 TV '보여 주기 모드' — 설계 한 장

> 2026-09-24 · 주민 연기 담당 · 보스 요청(원본 마을 묶음 다음) · **설계만(코드 0)**
> 근거: 창조자의 눈 30회 §3 "선생님 눈 — 교실 TV(1920×1080)에서"(`docs/creator_notes/2026-09-23_round30.md`) · 어설픔 목록 30-ⓒ67

## 두 문장

1. **아이가 새로 누리는 것** — 선생님이 교실 TV에 마을을 띄우면, 교실 뒷자리 아이도 **자기가 지은 집 앞의 사람과 "💧 14채" 같은 말을 읽고** "저기 우리 집!" 하고 가리킬 수 있다.
2. **아이가 설명할 수 있는 관계** — 반 전체가 한 화면을 보며 "이 우물이 놓이자 저 거리 사람들이 물동이를 들고 다닌다"처럼 **한 사람이 둔 것과 이웃의 삶 사이의 관계**를 함께 말할 수 있다(지금은 글과 사람이 안 읽혀 그 말을 선생님 혼자 한다).

## 무엇이 문제인가 (사실 · 창조자 30회 · 1920×1080 · 그래픽 '높음')

| 무엇 | 지금 크기 | 교실 뒤 7~8m |
|---|---|---|
| 한 칸 | 44px | 집(≈90px)은 보임 |
| 사람 | 몇 px ~ 10px 안팎의 점 | **안 보임** — '빈 거리' |
| 윗줄 글씨(단추·시계·인구) | 13~13.5px(화면 높이 1.2%) | **못 읽음** |
| 토스트 | 13.5px 굵게 | 대비는 좋으나 **작아 못 읽음** |
| 윗줄 도움말 | 약 11px 회색 | 앞줄도 어려움 |
| 아래 물건 상자(트레이) | 높이 약 180px(**화면의 17%**) | 마을을 가리는 검은 띠 |

해석: 마을 **그림**은 읽히고 **글·사람**은 안 읽힌다. 선생님은 "저 가게 거리를 보세요"까지는 할 수 있어도, "토스트를 읽어 볼까요"는 못 한다.

## 무엇을 하나 — 한 스위치, 세 가지

`VRULES.showMode = { on: false, text: 2.4, folk: 1.6, zoom: 1.25 }` · `body.show` 클래스 하나 · 분류 **'보기'**(판정·저장 0).

| | 바뀌는 것 | 어떻게(기존 틀 재사용) |
|---|---|---|
| **숨김** | 트레이 · 윗줄 도움말 · 미니맵 · 칩 줄(💼·🏠 등) · 제 단추들(↺ 처음부터 · 되돌리기) | **사진 모드의 `body.photo` 숨김 목록을 그대로** `body.show` 에도(한 줄씩 덧붙임). 사진 모드처럼 놓기·치우기 상태는 풀어 둔다(`setMode(null)`). |
| **크게 · 글** | 윗줄은 **셋만 남김**(마을 이름 · 시계 · 인구) ×2.4 · 토스트 13.5 → **32px** · 떠오르는 글자(`.fword` 22 → 44px) · 누른 집 카드·`#why` ×2 | CSS 변수 하나(`--showK`)로 곱함. 긴 토스트는 두 줄로 접힘(`max-width: 70vw`). |
| **크게 · 사람** | 사람 ×1.6(키 ≈ 10px → **16px 이상**) · 말풍선 아이콘 ×1.4 | **그림만**: `drawFolks`·곁 자리·수레 끄는 이웃이 `folk` 배율을 곱한다. 사람이 커지면 가까이 선 둘이 겹쳐 보이므로 ACT-SPACE 간격(`gap`·`pairGap`)도 같은 배율로. |
| 시점 | 들어갈 때 한 번 조금 가까이(`zoom` ×1.25 · 사진 모드와 같은 `camEl`) — 나오면 원래대로 | `photoMode` 의 `PHOTO.keep` 처럼 저장했다가 되돌림. |

**들어가기 · 나가기 — 선생님 단추 하나.** ⚙(보기 설정) 안에 `📺 보여 주기` 하나 · 켜진 동안에는 화면 오른쪽 위 구석에 작은 `📺 끝` 하나만 남는다(Esc 도 끝). 주소 `?show=1` 로도 켤 수 있다(교실 PC 즐겨찾기). 학생 기기에서 눌러도 해롭지 않으므로 숨기지 않는다.

**켜진 동안 되는 것:** 집·가게를 누르면 카드(크게) · 배속 1/2/4 · 판 끌기·확대. **안 되는 것:** 놓기·치우기(트레이가 없으니 자연히) — TV 앞에서 선생님의 손이 실수로 마을을 바꾸지 않게.

## 다 됐다고 말하는 기준 (헤드리스 1920×1080에서 잰다 · 창 안 띄움)

- 윗줄 남은 글씨 ≥ **32px** · 토스트 ≥ **32px**(화면 높이 3%)
- 기본 시점에서 사람 키(그려진 부위 상자) ≥ **16px**
- 마을을 가리는 띠 **0%**(트레이 숨김) — 마을이 화면의 90% 이상
- 끄면 모든 값이 켜기 전과 **같다**(시점·배율·글씨 · 저장본 바이트 동일)
- 판정 지표 불변(기준 ① — 그림·CSS만) · 사냥 하네스 '오래 포갬' 0(사람 ×1.6 에서도)
- **남는 확인(ⓒ67)**: 실제 교실 TV 뒷자리에서 선생님이 **무엇을 가리키며 말하는지** — 글과 사람이 읽히는 것이 실제로 도움이 되는지.

## 나눠서 만든다 (한 PR 씩)

1. **숨김 + 글씨**(CSS · `body.show` · ⚙ 단추 · `?show=1`) — 가장 싸고 효과가 큼.
2. **사람 크게**(그림 배율 한 곳 · 간격 같은 배율) — 1 뒤에 실제 TV 사진으로 필요한지 보고.
3. (필요하면) 시점 조정 값 다듬기.

## 안 하는 것

판서·레이저 포인터 · 학생별 화면 모으기 · 자동 카메라 투어 · 선생님 계정 구분(마을엔 계정이 없다 — 단추는 누구나 누를 수 있어도 해가 없게만).

## 조심할 것

- 좁은 화면(폭 1280 미만)에서는 글씨 ×2.4 가 넘친다 → 켜기는 되지만 배율을 `min(2.4, innerWidth/800)` 으로.
- 토스트가 커지면 가운데 위를 더 가린다 — 두 줄 접힘 + 떠오르는 글자(물건 위)로 흩어 두었으니 겹침은 적다(#911).
- 사진 모드와 동시에 켜지지 않게(둘 중 하나를 켜면 다른 하나는 끔).
