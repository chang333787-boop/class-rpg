## 2. 화면(크롬북 1366×768 · 1366×600 · 휴대폰 390×844)
| 기준 | 어떻게 지켰나 |
|---|---|
| 내용이 화면보다 길어도 제목이 위로 잘리지 않음 | 가운데 맞춤은 `.kmain.vc` · `.kcenter>*{margin:auto}`(justify-content:center 금지) |
| '시작'처럼 누를 단추가 화면 밖으로 안 감 | 긴 안내 화면의 단추 줄은 `.btnrow.sticky` |
| 창(하는 법 · 그만할까요)이 떠 있는 동안 시간이 흐르지 않음 | `clockPause/clockResume`(시계 하나 · 걸린 시간도 창 시간을 뺌) |
| 휴대폰에서 숫자판 · '다음 칸'이 한 화면 | 숫자판 4칸(계산기 모양) · 시간 링 64px · '지금 할 일' 한 줄 |
| 같이 풀기에서 아직 안 푼 단계가 답을 미리 말하지 않음 | 안 푼 단계는 번호만 · 다리의 같은 것 · 바뀐 것은 푼 뒤에(whyDone) |
| 알림(토스트)이 단추를 가리지 않음 | 같이 풀기 '같이 봤어요'는 단계 안 표시 |
| 옆 탑의 '지금 · 다음' 층이 보임 | 층 많으면 촘촘하게(dense) · 옆 칸만 스크롤해 가운데로 · 연습 옆 탑은 잠긴 도전 층 숨김 |
| 켤 순서 번호(①②)와 층 번호가 헷갈리지 않음 | '다음' 표시 하나만 |
| 글 속 분수도 문제와 같은 세로 분수 · 대분수가 줄에서 안 쪼개짐 | `rich()` · `.ftx` |
| 단추 44px 이상 · 가로 넘침 0 · 콘솔 오류 0 | 확인(390 · 1366) |
| 같은 뜻은 같은 말 | 아직 몰라요 · 알려 줘요 · 곱셈구구 빠르기 · 이렇게 풀어요 · 이야기 문제 모양 · '○개 층' |

## 3. 학습 흐름
- 문제은행: 계산 차시 연습 3번째마다 같은 숫자의 문장제(시간 1.6배 · 채점 규칙 그대로) — 진단한 곳에서 바로 반복(밖으로 보내지 않음)
- 개념 카드(층 안내): 이렇게 풀어요 · 예제 · 예전에 배운 것(다리) · **지난번 내 실수**
- 예제 읽은 시간 · 같이 푼 시간도 오늘 시간(addStudy · 문제 수는 늘리지 않음)
- 곱셈구구 빠르기는 16문제로 번호 고정(덤 문제는 번호를 늘리지 않음) · 불 점검에서 꺼지면 마지막 답을 보여 줌

## 4. 선생님 · 학부모
- 5초 안에 '누가 도움이 필요한지': 수업 추천이 맨 위 · 아이별은 '선생님과' → '오늘 안 함' 순 · 미니 탑 범례
- 학습지 인쇄(print.js): 층마다 이렇게 풀어요 · 예제 · 연습 8문제(문장제 2) · 정답 — 아이 상세 '학습지 인쇄' · 수업 추천 '이 층들 학습지 인쇄(반 전체)'
