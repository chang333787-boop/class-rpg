# 상용 서비스 수준까지 남은 격차 (2026-09-20)

> 밸런스·상용화 점검 세션(맥북, 읽기 전용). 기준: **"다른 학교·다른 교사가 써도 되는가."** 우리 반 한 학급이 쓰는 데는 지금도 돌아간다 — 이 문서는 그 다음 단계까지의 거리다.
> 방법: main `d7b2a63` 의 코드를 읽고 줄 번호를 직접 확인했다. **운영 DB·Firebase 콘솔에는 붙지 않았다** — 그래서 "콘솔에 지금 어떤 규칙이 게시돼 있는가" 같은 것은 **확인 못 함**으로 적었다.
> 표기: **(확인)** = 코드 줄을 직접 읽음 · **(문서)** = 저장소 문서가 그렇게 말함(지금도 그런지는 미확인) · **(추정)** = 근거는 있으나 확인 못 함 · **(못 찾음)** = 여러 표현으로 찾았으나 없음 — "없다"가 아니라 "못 찾았다".
> 크기: **소** = 반나절~하루, 한 파일 · **중** = 며칠, 여러 파일·검증 필요 · **대** = 1주 이상, 구조 변경·데이터 이전.
