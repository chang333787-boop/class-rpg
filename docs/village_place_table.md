## ① 마을의 바닥 종류 (= `on` 의 열)

지금 마을에 있는 바닥은 일곱 가지다. **흙·모래 땅은 아직 없다**(설계안 표의 '흙' 열은 마을에선 비움 — ⑤ 빠진 조각).

| 열 | 무엇 | 층 | 윗면 높이 | 비고 |
|---|---|---|---|---|
| 풀 | 구역의 기본 땅(아무것도 안 놓은 칸) | 땅 | 0 | |
| 잔디 | `lawn` 잔디밭 | 땅 | 0.12 | |
| 자갈 | `gravel` 자갈길 — **이름은 길인데 `road` 가 아니다**(주민이 안 걷는다) → 땅으로 분류 | 땅 | 0.14 | |
| 꽃밭 | `flower` | 땅 | 0.28 (+꽃 1.4 까지) | 밟으면 안 되는 땅 |
| 광장 | `plaza` 3×3 포장 | 땅 | 0.22 | |
| 길 | `road`·`avenue`·`crosswalk`·`treerow`·다리 2종 | 길 | 0.17~0.20 | 주민이 걷는다 |
| 물 | `pond` 연못 2×2 | 땅 | 0.35(돌 턱) | 마을엔 아직 강·바다 칸이 없다 |

**서는 높이 규칙(모양):** 물건·길가 물건은 **자기 아래 층의 윗면 높이에 선다.** 지금은 전부 0 에 서 있어서, 층이 겹치면 길 위 벤치 다리가 0.2, 꽃밭 위 나무 밑동이 0.28 파묻힌다. 구현 때 `partMatrix` 의 y 에 아래 층 윗면을 더하면 된다(모양 쪽 요구는 이 한 줄).

## ③ 층이 겹칠 때 어색한 곳 — 모양 쪽에서 준비할 것

1. **꽃밭 위 나무·덤불.** #445 의 새 꽃밭은 키 큰 꽃이 1.4 까지 올라와 나무 줄기(폭 0.5~0.9)를 뚫는다. → `buildFlowerBeds` 에 **가운데 반지름 0.8 을 비운 벌 2개**(나무용)와 **깔개만 있는 벌 1개**(덤불·집 둘레용)를 더한다. 같은 함수에 인자 하나 — 삼각형은 오히려 준다. 어느 벌을 쓸지는 "그 칸 물건 층에 무엇이 있나"로 고른다(저장 0).
2. **테두리 조각의 치수.** 한 변 = 길이 4(한 칸). 울타리 두께 0.2 · 돌담 **0.8 → 0.6**(선 위에 서면 양쪽 칸을 0.3 씩 먹는다. 0.8 이면 길 포장 가장자리 줄눈을 덮는다). 기둥은 **변의 시작 끝에만** 1개(서·북 규칙과 같은 방향) + 열린 끝에 마감 기둥 — 그래야 모퉁이에서 기둥 넷이 겹치지 않는다. **문**은 같은 변 조각의 변형(가운데 2 가 열림, 기둥 둘이 조금 높음).
3. **길 위 물건의 높이.** 길 윗면 0.17~0.20, 광장 0.22, 꽃밭 0.28. 물건이 0 에 서면 다리가 묻힌다 → ①의 '서는 높이 규칙'.
4. **길을 깔 때 밑의 땅.** 길판이 칸을 100% 덮으므로 밑 땅은 안 보이지만, 꽃밭은 꽃이 길을 뚫고 나온다 → 길을 깔면 그 칸 땅을 풀로 되돌린다(또는 길 아래 꽃밭 ❌ — 표는 되돌림 쪽으로 적었다. 아이가 길을 치우면 꽃밭이 사라져 있는 건 설명이 필요해서, **"길 밑의 꽃은 뽑혔어요"** 한 줄).
5. **집 마당.** 집 둘레 1.2 는 밑의 땅이 그대로 보인다. 이건 버그가 아니라 **선물** — 잔디 마당·자갈 마당·광장 위 집이 공짜로 생긴다. 집 모습 3단계(설계안 ③)의 마당 바닥판은 아이가 깐 땅이 없을 때만 그린다.
6. **연못과 광장.** 둘 다 돌 턱이 있는 큰 덩이라 서로 겹치면 턱이 이중으로 보인다 → 서로 ❌.

## ⑤ 표를 채우다 보인 빠진 조각 (제안 — [`village-design-20260920.md`](village-design-20260920.md) ② 에 더함)
- **1×1 포장(광장 바닥)** — 지금 광장은 3×3 한 덩이라 '땅 층'의 맛(포장 위 분수·벤치·나무 구멍)이 안 난다. 층 구조의 **첫 수혜 조각**.
- **나무 구멍 포장** — 광장 위 나무.
- **흙·모래 땅** — 놀이터 밑·밭·공사 중인 땅. '문제가 눈에 보이게'의 재료이기도 하다(풀이 닳은 길).
- **물 칸(개울 1×1)** — 다리가 제자리를 찾는다. 연잎·갈대·오리는 그 다음.
- **산울타리(테두리)** — 덤불을 edge 로.

## ⑥ 프로그램 담당에게 (접점만)
- 필드 제안: `place:'ground'|'path'|'object'|'roadside'|'edge'` · `on:[…]`(위 표의 ✅ 열). K 47줄에 직접 적지 말고 **#438 의 `USE_TABS` 처럼 새 블록 표 하나**로 덮어쓰면 학교 판 K 와 안 부딪힌다.
- 모양 쪽 요구 둘: ① 물건의 y = 아래 층 윗면 ② 꽃밭 벌 고르기에 "그 칸 물건 층" 을 넘겨 줄 것.
- 1단계(`canPlace` 에 `on` 검사 + 이유 말)는 저장을 안 건드리므로 지금 표만으로 시작할 수 있다 — 다만 **지금은 단층이라 `on` 이 '옆에 무엇이 있나'가 아니라 '그 칸이 비었나'뿐**이다. 실제 효과는 2단계(땅 층)부터.
